OWL and the NSHD Showcase currently provide access to around 28,898 variables — those that have been cleaned and enhanced as part of the Metadata Enhancement Project. The full NSHD repository contains approximately 35,000+ variables; the remaining ~6,102 are available on Condor. New variables are added to OWL and the Showcase periodically as each questionnaire is processed and deposited. See below for more details for what is available on this platform.

Single-sweep vs multi-sweep Field IDs

Of the 23,021 unique Showcase Field IDs, 10% were collected at more than one time point with identical question text and coding. These multi-sweep fields are the ones where the NSHD Showcase groups instances together for direct longitudinal comparison.

Single-sweep: 20,669 (90%). Multi-sweep: 2,352 (10%).

Note: this chart groups sweeps by distinct collection year per Field ID. A small number of Field IDs were collected more than once within the same labelled year — for example, Covid wave 1 and wave 2 are both recorded under the year 2020, despite being separate questionnaires collected months apart — and are counted here as single-sweep. Because of this, the multi-sweep count above is slightly higher than the number of longitudinal fields shown on the Longitudinal Variables page, which counts sweeps individually rather than by distinct year.

Longitudinal tracking depth

Of 23,021 unique Showcase Field IDs, 2,352 (10%) have been collected at more than one sweep, some for decades. The most consistently tracked variable is Interview contact status (recoded) at age 19 (Field ID 6200), collected across 27 sweeps spanning 77 years: 1948, 1950, 1952, 1953, 1954, 1955, 1956, 1957, 1959, 1961, 1965, 1966, 1968, 1969, 1971, 1972, 1977, 1982, 1989, 1999, 2006-10, 2014, 2015, 2021, 2022, 2023, 2025.

Sweep counts listed in page text.

Chart shows Field IDs collected at 2 or more sweeps only — the 20,669 fields collected just once are excluded so the repeat-collection pattern is visible. "Sweeps" counts distinct collection years per Field ID — see the note under Single-sweep vs multi-sweep above for an edge case involving same-year sweeps.

Note: these counts only include truly longitudinal variables — those collected with identical question text and coding at every sweep they appear in, which is why they share one Showcase Field ID across sweeps. If a question was re-asked with different wording, response options, or coding at a later sweep, it is assigned a separate Field ID and is not counted as a repeat sweep of the original here, even though it may cover the same underlying measure.

Variables by life stage

The volume of variables reflects the intensity of data collection at each phase of life. The richest coverage is at ages 56–65 — corresponding to the major 2006–2010 clinic visit — followed by ages 46–55 and 66–75. Early-life coverage (birth to age 25) is smaller in scale but represents foundational measures collected across the study's first two decades.

Variables by collection year

The chart shows variable counts for each collection year or period. The dominant peaks reflect the major intensive data collection sweeps — 2006-10 (8,581), 1999 (4,029), 1989 (2,680), 1982 (2,334). Early sweeps in the 1940s–70s have fewer variables, reflecting the simpler instruments used in those decades.
