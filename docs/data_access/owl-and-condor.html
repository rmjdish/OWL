Using OWL and Condor Together

How OWL and Condor complement each other for variable discovery, basket building, and submitting a data request.

On this page

  • OWL vs Condor
  • Recommended workflow
Back to Accessing NSHD Data

OWL and Condor are both places where you can search for variables and build a basket, but they serve different purposes and cover different scopes. OWL gives you access to around 28,000 variables that have been cleaned and enhanced as part of the Metadata Enhancement Project, alongside questionnaires, topic pages, and detailed variable metadata — all without registration. Condor holds the full set of 35,000+ variables and is the only platform where a formal data request can be submitted. The two platforms work best together: use OWL to discover and refine your variable list, then upload your basket to Condor to finalise and submit your request.

You can check which questionnaires have been cleaned and are currently available on OWL and the Showcase on the NSHD Showcase Essential Information page.

OWL vs Condor — what each platform offers

The table below shows what each platform offers for variable discovery and basket building. Both let you search for variables and build a basket — but only a Condor basket can be submitted as a formal data request.

OWL

Best for discovery and exploration. OWL provides rich context around each variable — questionnaire instruments, topic documentation, and detailed metadata — that makes it easier to identify exactly the right variables before committing to a formal request.

~28,000 cleaned variables ✓ Search data dictionary ✓ Browse by category ✓ Questionnaire access ✓ Topic pages ✓ Variable metadata & distributions ✓ Build basket ✓ Download basket as CSV ✗ Cannot submit data request
No registration required

Condor

Required for formal data requests. Condor holds the complete NSHD variable set including variables not yet available on OWL. Use it to upload your OWL basket, make any final adjustments, and submit your request.

35,000+ full variable set ✓ Search variables ✓ Build basket ✓ Upload OWL basket ✓ Modify basket after upload ✓ Submit data request ✓ Manage approved projects ✓ Add users / request more variables
Registration required
Only Condor baskets can be submitted as formal data requests. A basket built on OWL is for exploration and reference only — it must be uploaded to Condor before a data application can be made.

Recommended workflow

The most effective approach is to use OWL for variable discovery and basket building, then move to Condor to finalise and submit your request.

1

Discover variables on OWL — no registration needed

Use the Search Data Dictionary, Browse by Category, questionnaire pages, and topic documentation to identify the variables relevant to your research question. Review each variable's metadata page to check its provenance, coding, sensitivity status, and frequency distribution. Use the NSHD Showcase (via the Field ID) to check participant counts and sweep-by-sweep distributions for shortlisted variables.

2

Build and download your OWL basket

Add variables to your basket using the checkboxes on any results table, or the Add All button to add an entire page at once. Your basket persists as you move between Search, Browse, and other tools. When ready, download it as a CSV — this gives you a portable reference list you can review, share with colleagues, or use to plan your data request before involving Condor.

3

Upload your basket to Condor and finalise

Register on Condor and import your OWL CSV basket. Within Condor you can make further adjustments — adding variables from the full 35,000+ set that are not yet available on OWL, removing variables, or splitting the basket if it exceeds 500 variables. All modifications to the basket for submission must be made within Condor.

4

Submit your request from Condor

Once your Condor basket is finalised, submit a formal data access request. Each basket submission is limited to a maximum of 500 variables — if your project requires more, split across multiple baskets for the same project and submit them separately. Complete your access prerequisites and data access request form via Skylark to accompany your Condor submission.

OWL currently covers around 28,000 variables — those cleaned as part of the Metadata Enhancement Project. If variables you need are not yet on OWL, you can search for them directly within Condor. Check the NSHD Showcase Essential Information page to see which questionnaires have been processed and are available on OWL.
