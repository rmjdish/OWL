OWL, the NSHD Showcase and Condor

How the three variable platforms relate to each other and which to use at each stage of your research.

On this page

  • Platform comparison
  • OWL & Showcase together
  • Recommended workflow
Back to Accessing NSHD Data

OWL, the NSHD Showcase, and Condor each approach NSHD variables from a different angle. OWL and the Showcase both cover around 28,000 variables that have been cleaned and enhanced as part of the Metadata Enhancement Project — they are complementary sources designed to be used together, linked via the Field ID on every variable. Condor holds the full 35,000+ variable set and is the only place where a formal data request can be submitted. None of OWL or the Showcase require registration.

Platform comparison

The three platforms serve different purposes and offer different information about the same variables. Use the comparison below to understand what each one contributes.

OWL

Variable discovery with rich documentation context — questionnaires, topic pages, linked longitudinal variables, and per-variable metadata. Best starting point for any research.

~28,000 cleaned variables ✓ Search & browse ✓ Questionnaire access ✓ Topic pages ✓ Variable metadata page ✓ Multiple category memberships ✓ Value labels ✓ Flexible longitudinal linking ✓ Distribution for this variable ✓ Download basket as CSV ✗ Cannot submit data request
No registration

NSHD Showcase

Data portal view of variables — participant counts, sweep-by-sweep distributions, and technical data attributes. Best for confirming coverage and comparing a measure across time points.

~28,000 cleaned variables ✓ Participant & item counts ✓ Distributions per sweep (Instances) ✓ Strict longitudinal grouping ✓ Full category hierarchy path ✓ Value Type, Sexed, Strata, Array ✓ NSHD variable names per instance ✗ No questionnaire access ✗ No basket building ✗ Cannot submit data request
No registration

Condor

The data request platform. Holds the full variable set including those not yet on OWL or the Showcase. Only Condor baskets can be submitted as formal data requests.

35,000+ full variable set ✓ Search variables ✓ Browse by category ✓ Build basket ✓ Upload OWL basket ✓ Modify basket ✓ Save basket ✓ Share basket ✓ Submit data request ✗ No variable metadata page ✗ No multiple category memberships ✗ No value labels ✗ No flexible longitudinal linking ✗ No questionnaire access ✗ No topic pages
Registration required
Only Condor baskets can be submitted as formal data requests. Neither OWL baskets nor the NSHD Showcase can be used to submit a data application — both are for discovery and exploration only.

How OWL and the Showcase work together

OWL and the NSHD Showcase are designed to complement each other. They cover the same pool of around 28,000 cleaned variables but present different information about each one. The Field ID is the link between them — it appears on OWL's variable metadata page and in Search Data Dictionary and Browse by Category results tables, and clicking it opens the corresponding Showcase entry.

Use OWL when you need

  • The original questionnaire wording and response options for a variable
  • The form, question number, and year of collection
  • All categories a variable belongs to — a variable can appear in multiple
  • Flexible longitudinal linking — variables connected regardless of coding changes
  • Notes, caveats, or recoding details specific to the variable
  • Whether a variable is derived, sensitive, or has a later version
  • To build and download a basket for uploading to Condor

Use the Showcase when you need

  • Total participant and item counts across all sweeps for a field
  • Sweep-by-sweep distribution charts and statistics on one page (Instances)
  • Strict like-for-like comparison across sweeps — identical question text and coding only
  • The full hierarchical category path showing where a variable sits
  • Technical attributes — Value Type, Sexed, Strata, Array
  • The NSHD variable name for a specific sweep of a multi-instance field
OWL and the Showcase take different approaches to longitudinal grouping. The Showcase only groups variables where question text and coding are identical across sweeps. OWL's Linked & Longitudinal section is more flexible — it connects variables for any reason, including where coding or wording changed between sweeps. See the Variable Metadata guide for a full comparison.

Recommended workflow across all three platforms

The three platforms work best in sequence — use OWL and the Showcase together for discovery, then move to Condor to finalise and submit your request.

1

Start on OWL — discover and contextualise

Search the data dictionary, browse by category, and read questionnaire and topic pages to identify candidate variables. Review each variable's metadata page for provenance, coding, derived status, and any caveats. No registration needed. Add variables to your basket as you go.

2

Cross-check on the NSHD Showcase

For shortlisted variables, click the Field ID — available in Search Data Dictionary results, Browse by Category results, and on the variable metadata page — to open the Showcase entry. Check participant counts at each sweep, compare distributions across time points using the Instances section, and confirm the variable's technical attributes before committing to a request.

3

Download your OWL basket and upload to Condor

Download your finalised OWL basket as a CSV, then import it into Condor. Within Condor you can make further adjustments — adding variables from the full 35,000+ set not yet available on OWL or the Showcase, removing variables, or splitting into multiple baskets if the total exceeds 500 variables per submission.

4

Submit from Condor and apply via Skylark

Submit your formal data access request from Condor. Complete access prerequisites and submit your Data Access Request Form via Skylark to accompany your Condor submission.

OWL and the Showcase currently cover around 28,000 variables — those cleaned as part of the Metadata Enhancement Project. Variables not yet available on OWL or the Showcase can be found and added to your basket directly within Condor. Check the NSHD Showcase Essential Information page for the current list of processed questionnaires.
