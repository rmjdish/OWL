Variable Metadata

Variable-level metadata is available on both OWL and Condor — the same underlying information, presented differently on each.

  • OWL vs Condor
  • Which should I use?
Back to Accessing NSHD Data

Every NSHD variable has a metadata page on both OWL and Condor. The OWL Variable Metadata page and the Condor Variable Metadata page present the same underlying variable-level metadata — questionnaire provenance, longitudinal linkage, category placement, and disclosure-controlled distribution summaries — but the two platforms now differ enough in presentation and capability to warrant their own sections below: OWL’s tab-based layout, split longitudinal linkage, and enhanced distribution statistics go well beyond Condor’s single flat table. Use either to build a complete picture of a variable before including it in a data access request.

OWL Variable Metadata Page

On OWL, the variable metadata page is opened by clicking any variable name wherever it appears — in any of the searches, or in the table at the end of this documentation.

It uses a tab-based layout that groups information into six panels, so you can go straight to the section you need without scrolling. Tabs show a count of the items they contain where relevant.

The six tabs

MetadataEvery core field — questionnaire provenance, units, derived status, sensitivity and notes. The full field list is in the comparison table below.
Linked & Longitudinal (13)Other sweeps and related variables, split into two colour-coded subsections (see below).
Documents (1)Documentation files and direct links to questionnaires attached at the individual variable level.
CategoriesEvery category the variable belongs to, with a description. Each links to its Browse by Category page, which shows the breadcrumb path.
Value LabelsFull coded value labels, with missing-value categories visually highlighted and explained.
DistributionThe chart and summary statistics side by side, with downloads (see below).

The count on the Linked & Longitudinal tab combines both subsections described below.

Linked & Longitudinal tab

This tab splits into two clearly labelled, colour-coded subsections, so you can tell at a glance how strong a connection between variables actually is:

Truly Longitudinal Strict
Variables sharing the same Field ID — identical question text and response coding across sweeps. Directly comparable measurements guaranteed.
Linked variables Flexible
Variables connected by a shared linking measure — may include the same construct with different wording or coding. Review before treating as directly comparable.

Any variable that shares its Field ID with another appears only in the purple Truly Longitudinal subsection, so the green Linked variables subsection shows only genuinely different-Field-ID connections — the two lists never overlap.

Distribution tab

OWL’s distribution panel goes further than a basic chart-and-count view, with extra summaries for each variable type and downloads for both the chart and the statistics:

Continuous variables

  • Box-and-whisker summary above the histogram
  • Median, IQR and range added alongside the deciles, mean and standard deviation

Categorical variables

  • 100% stacked summary bar
  • Percentage column alongside the counts

Downloads (both types)

  • The plot image
  • The full statistics table

“View all sweeps”

For any variable that has at least one other sweep sharing its Field ID (i.e. it appears in the purple Truly Longitudinal subsection above), a “View all sweeps” button appears on both the Distribution and Linked & Longitudinal tabs. Both link to the same page, which shows:

  • Every sweep’s distribution side by side, each on its own independent axis
  • One merged statistics table covering the whole group
  • Its own CSV download (the merged table) and a single combined image of every sweep’s chart

Variables with no Truly Longitudinal group show neither button.

OWL vs Condor presentation: The same underlying links are available on both platforms, but only OWL separates them into Truly Longitudinal (Strict) and Linked variables (Flexible) subsections — see the Condor Metadata Page section below for how Condor presents the same links. If you need to know whether a comparison is strictly valid, check this OWL page rather than Condor directly.

Condor Variable Metadata Page

On Condor, the same underlying variable metadata is opened by clicking a variable name within a basket. Condor presents it as a single, flat, undifferentiated table — there is no tab-based layout and no panels to navigate between; every field, every linked variable, and the distribution chart appear one after another on one page.

MetadataAll core fields listed in one continuous table — Variable, Field ID, Label, Card Number, Form, Question, Year, Units, Derived Status, Later Version, Sensitive, Reason Public, Reason Sensitive, Notes
Linked & LongitudinalOne combined list — Truly Longitudinal and Linked variables are not distinguished from one another
DocumentsQuestionnaire links and technical docs attached at variable level, same as OWL
CategoriesAll category memberships listed
Value LabelsFull coded value labels listed
DistributionBasic bar chart/histogram with core stats (counts, deciles, mean, SD) — no box-and-whisker, no stacked bar, no downloads

Because everything sits in one table rather than separated tabs, Condor’s page can take more scrolling to get through for a variable with a lot of linked variables or documents attached — there’s no jumping straight to the section you need.

Condor vs OWL presentation: All linked and longitudinal variables are listed together, undifferentiated — Condor does not indicate which connections share an identical Field ID and coding versus which are linked more loosely, and the Distribution section only shows the basic chart and core statistics, with no download option for either the plot or the stats table. See the OWL Metadata Page section above for the enhanced version of this same information.

Which should I use?

Most questions can be answered on either platform. A few can only be answered on OWL.

Either platform works

I want to know which form, question number, and year a variable was collected

→ OWL or Condor Metadata Page — Form, Question, Card Number, and Year fields give full questionnaire provenance on either platform

I want to know if a variable is derived or has sensitivity restrictions

→ OWL or Condor Metadata Page — Derived Status, Sensitive, Reason Public, and Reason Sensitive fields, same on both platforms

I want to check if a newer or corrected version of a variable exists

→ OWL or Condor Metadata Page — Later Version field tells you if the variable has been superseded and what to use instead

I want additional context about how a variable was measured or any known caveats

→ OWL or Condor Metadata Page — Notes may contain measurement conditions, recoding details, or quality caveats

I want to see all the categories a variable belongs to

→ OWL or Condor Metadata Page — shows all category memberships; a variable can belong to multiple

I want to link variables across sweeps even if the coding or wording changed

→ OWL or Condor Metadata Page — both link variables for any reason, regardless of coding; OWL labels this the Linked variables subsection, Condor lists it alongside Truly Longitudinal links in the same table

OWL only

I want to compare distributions across all sweeps on one page

→ OWL Metadata Page — the “View all sweeps” button (Distribution or Linked & Longitudinal tab) shows every Truly Longitudinal sweep together, with a merged statistics table and downloads

I want to download every sweep’s distribution together, not just one variable’s

→ OWL Metadata Page — the “View all sweeps” page has its own CSV download (the full merged statistics table) and a single combined image covering every sweep’s chart; this isn’t available on Condor

I want to know whether a comparison across sweeps is strictly valid before I rely on it

→ OWL Metadata Page — check whether the variable appears in the purple Truly Longitudinal subsection (same Field ID, guaranteed comparable) or only the green Linked variables subsection (coding may differ); Condor lists both together so this distinction isn’t visible there

I want to save the distribution chart or statistics table for a variable outside OWL

→ OWL Metadata Page — the Distribution tab has separate download buttons for the plot image and the full statistics table; this isn’t available on Condor’s version of the page

I want to see where a variable sits in the category hierarchy

→ OWL Metadata Page — each category in the Categories tab links to its Browse by Category page, which shows the full breadcrumb path
