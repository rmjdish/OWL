Variable Metadata

Two complementary sources of variable-level metadata — available on both OWL and Condor — each presenting different information about the same variables.

Every NSHD variable has metadata available from two complementary sources. The NSHD Condor/OWL Metadata page presents the same variable-level metadata on both OWL and Condor — questionnaire provenance, longitudinal linkage, category placement, and disclosure-controlled distribution summaries. The NSHD Showcase Metadata page groups variables that share the same Field ID and identical question text and coding onto a single page, broken down by sweep via Instances. Together they give a complete picture of a variable before including it in a data access request.

NSHD Condor/OWL Metadata Page

The NSHD Condor/OWL Metadata page presents the same underlying metadata for each variable on both platforms. On OWL, it is accessed by clicking any variable name in a results table — Search Data Dictionary, Browse by Category, Popular Variables, or the Basket page. On Condor, clicking a variable name within a basket opens the equivalent metadata view.

While the metadata content is identical on both platforms, the OWL presentation uses a redesigned tab-based layout that groups information into six panels — making it faster to navigate directly to the section you need without scrolling. Each tab shows a count of items it contains where relevant, and the distribution panel places the chart and summary statistics side by side:

Metadata Linked & Longitudinal (13) Documents (1) Categories Value Labels Distribution

The Linked and Longitudinal Variables section is deliberately flexible — it can connect any variables together regardless of whether their coding matches, making it suitable for tracing a construct across sweeps even where the question wording or response scale changed, or for grouping variables that belong to the same instrument or scale. Documentation files and direct links to questionnaires can also be attached at the individual variable level.

OWL vs Condor presentation: The same metadata fields are available on both platforms, but the tab-based layout shown here — with section counts, side-by-side chart and statistics, and colour-coded panels — is specific to OWL. If you are viewing a variable on Condor, the metadata is presented in a single-page layout without tabs.

NSHD Showcase Metadata Page

Accessed via the Field ID link — available in Search Data Dictionary, Browse by Category results tables, and on the NSHD metadata page. The Showcase groups variables that share the same Field ID and have identical question text and response coding onto a single page, with each sweep presented as a separate instance. This means the Showcase gives a clean, directly comparable view of the same measure across time — but only where strict equivalence holds. The same disclosure controls apply as on the NSHD metadata page.

The NSHD Showcase is built on the same platform as the UK Biobank Data Showcase. Researchers familiar with the UK Biobank will find the structure and navigation immediately recognisable, making the Showcase a particularly efficient starting point for those already experienced with UK Biobank variable discovery.

Which should I use?

I want to know which form, question number, and year a variable was collected

→ NSHD Condor/OWL Metadata Page — Form, Question, Card Number, and Year fields give full questionnaire provenance

I want to compare distributions across all sweeps on one page

→ NSHD Showcase Metadata Page — Instances shows charts and stats per sweep where coding is identical

I want to know if a variable is derived or has sensitivity restrictions

→ NSHD Condor/OWL Metadata Page — Derived Status, Sensitive, Reason Public, and Reason Sensitive fields

I want to know the exact data type of a variable

→ NSHD Showcase Metadata Page — Value Type field explicitly states categorical single, categorical multiple, or continuous

I want to check if a newer or corrected version of a variable exists

→ NSHD Condor/OWL Metadata Page — Later Version field tells you if the variable has been superseded and what to use instead

I want to see the full category hierarchy for a variable

→ NSHD Showcase Metadata Page — shows the parent and child category structure for the variable's primary category

I want additional context about how a variable was measured or any known caveats

→ NSHD Condor/OWL Metadata Page — Notes may contain measurement conditions, recoding details, or quality caveats not available on the Showcase

I want to find the NSHD variable name for a specific sweep of a Showcase field

→ NSHD Showcase Metadata Page — Notes list the sweep-specific NSHD variable names and labels per instance

I want to see all the categories a variable belongs to

→ NSHD Condor/OWL Metadata Page — shows all category memberships; a variable can belong to multiple

I want to find the NSHD variable name for a specific sweep

→ NSHD Showcase Metadata Page — Notes list sweep-specific NSHD variable names and labels per instance

I want to link variables across sweeps even if the coding or wording changed

→ NSHD Condor/OWL Metadata Page — Linked & Longitudinal links any variables for any reason
