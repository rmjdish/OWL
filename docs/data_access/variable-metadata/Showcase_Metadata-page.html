NSHD Showcase Metadata Page

What the NSHD Showcase shows for each variable, and how it complements the NSHD Condor/OWL Metadata page.

On this page

  • Field Summary Panel
  • Data Section
  • Instances
  • Notes
Back to Variable Metadata

The NSHD Showcase is an externally managed portal for the NSHD cohort. Each NSHD variable links to its Showcase entry via the Field ID on the NSHD Condor/OWL Metadata page. The Showcase takes a structured approach to longitudinal grouping: variables that share the same Field ID and have identical question text and response coding are automatically grouped onto a single Showcase page, with each sweep presented as a separate instance. This means the Showcase gives a clean, directly comparable view of the same measure across time — but only where strict equivalence holds. Where question wording or coding changed between sweeps, those variables will appear on separate Showcase pages rather than being grouped. The same disclosure controls apply as on the NSHD Condor/OWL Metadata page — low cell count suppression for categorical variables and percentile trimming for continuous variables.

Field Summary Panel

At the top of every Showcase page is a summary panel listing key technical attributes of the field.

Attribute Description
Participants The number of unique study members who have at least one data point for this field. For multi-sweep fields, this is the count of distinct individuals across all time points combined, not per sweep.
Item count The total number of individual data points available across all instances. For multi-sweep fields this will exceed the participant count — for example, if 2,400 participants each have data at 4 time points, item count would be approximately 9,600.
Value Type The definitive statement of the variable's data type. Categorical (single) means one coded response per participant per instance. Categorical (multiple) means more than one response may be selected. Continuous means a numeric measured value such as height or blood pressure.
Sexed Whether the data covers both sexes or is specific to one sex — for example, female-only measures such as those from the Women's Health questionnaires.
Instances The number of time points at which this field was collected. Defined(1) means data from a single sweep; Defined(10) means data from ten different time points. Variables are only grouped into a multi-instance field on the Showcase where their question text and response coding are identical — sweeps where the wording or coding changed will appear as separate Showcase entries.
Item Type Data means the field contains actual collected measurements. Other types may indicate derived or administrative fields.
Strata Primary means core cohort data collected from the main NSHD study sample. Secondary indicates sub-study or derived data — for example from the Insight 46 sub-study.
Array Whether the field holds multiple measurements per participant per visit (array data). The majority of NSHD fields show No. Where Array is Yes, the data structure in a request will differ from a standard single-value field and should be taken into account when planning analysis.

Data Section

The Data section provides a top-level summary of what is available for the field. It states the total number of items and participants, identifies the data coding scheme used (linked to its own page on Datashare), and for single-instance fields shows a distribution chart directly.

For fields where combining instances across time points would be misleading — for example a self-rated health question asked at five different sweeps — the Data section notes this explicitly and does not show a combined chart. In these cases, individual charts are presented per instance in the Instances section below.

The same filtering rules apply here as on the NSHD Condor/OWL Metadata page:

  • Categorical variables — bar chart showing valid response categories. Any category with fewer than 10 responses is suppressed and will not appear. Missing codes are excluded.
  • Continuous variables — histogram showing values within the 5th–95th percentile range. Values in the bottom and top 5% are excluded, as are missing value codes. Summary statistics reflect this trimmed range.

Instances

The Instances section is the key feature that distinguishes the Showcase from the NSHD Condor/OWL Metadata page. Where the NSHD Condor/OWL Metadata page's Linked and Longitudinal section connects variables based on curatorial judgement — for any reason, regardless of coding — the Showcase Instances section only groups variables that share the same Field ID and have strictly identical question text and response coding. This means each instance represents a true like-for-like repetition of the same measure, making the sweep-by-sweep comparison directly meaningful without needing to account for differences in how the question was asked or responses coded.

For fields collected at more than one time point, the Instances section breaks the data down sweep by sweep. Each instance is labelled with its time period and a description of when and how the data was collected — for example, Instance 26: 2006–2010 — Survey carried out at age 60 to 64 years. Each instance entry shows the number of participants and items at that time point, and a distribution chart for that sweep alone.

Where a question was asked at multiple sweeps but the wording or coding changed between collections, those variables will not be grouped here — they will each appear on their own separate Showcase page. In that situation, the NSHD Condor/OWL Metadata page's Linked and Longitudinal section is the better place to find connections across those sweeps, since it allows linkage regardless of coding consistency.

The same filtering rules apply to instance-level charts as to the overall Data section:

  • Categorical variables — bar chart per instance. Categories with fewer than 10 responses are suppressed in the same way as on the NSHD Condor/OWL Metadata page. Missing codes are excluded.
  • Continuous variables — histogram per instance showing values within the 5th–95th percentile range, with the bottom and top 5% excluded. Summary statistics reflect this trimmed range, consistent with the NSHD Condor/OWL Metadata page display.

The instance numbers (26, 27, 32, 34, 35 etc.) correspond to study sweep codes used internally by Datashare. The label alongside each instance number gives the human-readable year range and collection context, making it straightforward to identify which sweep each chart represents without needing to know the coding scheme.

Notes

The Notes section contains free-text information about the field, primarily listing the NSHD variable names and labels covered by this Showcase entry. This is particularly useful for multi-instance fields, where a single Showcase field may encompass several distinct NSHD variables each collected at a different sweep.

For example, a self-rated health Showcase field collected at five time points might list in its Notes: ghi09 — How is your health in general? — at age 60–64 years, ghi14x — How is your health in general? — at age 68 years, ghi22x — at age 76 years, ghi23x — at age 77 years, ghi25x — at age 79 years. This makes it possible to cross-reference between the Showcase instance numbers and the specific NSHD variable names to use when building a basket or requesting data.

Not all Showcase fields have detailed notes — for simpler single-instance fields the notes may just confirm the NSHD variable name and label.
