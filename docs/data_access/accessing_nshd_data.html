Accessing NSHD Data

How the NSHD data sharing infrastructure works, and where to go at each stage of a data request.

On this page

  • OWL
  • NSHD Showcase
  • Condor
  • Skylark
  • Variable Metadata
  • Typical journey

The NSHD data sharing infrastructure is made up of four complementary platforms. OWL is where you discover and explore variables — searching by keyword, browsing by category, reading questionnaires and topic pages, and reviewing variable-level metadata. NSHD Showcase lets you inspect participant counts and distributions. Condor is where you build and submit your basket of variables for a data request. Skylark holds the data access information, prerequisites, and forms needed to make a formal application.

OWL — Variable Discovery & Documentation

You are here. The OWL (Online Wellbeing and Lifecourse Resource) is the starting point for any data request. Use it to:

  • Search the data dictionary by keyword across 35,000+ variables
  • Browse variables by topic category — Clinical data, Questionnaire data, and more — navigating a hierarchical category tree
  • Read questionnaire instruments from 1946 to the present day, with variables annotated directly on the source documents
  • Explore topic pages covering physical health, cognition, mental health, social circumstances, biological samples, and more
  • Review variable-level metadata including the questionnaire form, question number, year of collection, derived status, value labels, and frequency distributions
  • Compare variables across sources using the NSHD Metadata page and NSHD Showcase side by side
  • Build a basket of variables and export it as a CSV ready for a formal data request
No login is required to use OWL. All variable metadata, questionnaires, and topic pages are publicly accessible.

NSHD Showcase — Data Discovery Portal

The NSHD Showcase is an externally managed data discovery platform. For any variable you find on OWL, clicking the Field ID opens its Showcase entry, where you can see:

  • Total participant counts and item counts across all sweeps
  • Sweep-by-sweep distribution charts and summary statistics for each time point a variable was collected
  • The full coding scheme and value type (categorical single, categorical multiple, or continuous)
  • The full hierarchical category path showing where the variable sits in the topic structure
  • Which NSHD variable names correspond to each instance — useful when cross-referencing a multi-sweep Showcase field back to individual variable codes for a basket

The same disclosure controls apply on the Showcase as on OWL — response categories with fewer than 10 observations are suppressed, and continuous variable distributions are trimmed to the 5th–95th percentile range.

Condor — Variable Basket & Data Request Platform

Condor is the NSHD data sharing platform and holds around 35,000 variables. It is the system through which formal variable requests are submitted and managed. Once you have identified the variables you need using OWL and the Showcase, use Condor to:

  • Build a basket of variables by searching and selecting within Condor, or by importing a list of variable names from your OWL export
  • Submit a formal data access request linked to your project proposal
  • Track the status of an active request through the review and approval process
  • Add additional users to an approved project
  • Request additional variables for an already-approved project

All user accounts and baskets have been migrated from the previous system. If you are a new user you will need to register before building a basket.

Skylark — Data Access Information & Forms

Skylark is the NSHD data access information and forms portal. Questionnaire instruments and topic pages have moved to OWL — Skylark is now referenced for data access purposes only. Use Skylark for:

  • Data Access Request Form — the primary form for submitting a new data request
  • Additional Users / Data Request form — for adding users or requesting further variables on an approved project
  • DSH Output Request — for releasing outputs from the UCL Data Safe Haven portal
  • Project Extension Request — for extending the duration of an approved project
  • Data sharing process — step-by-step guidance on how NSHD data access works, including the review and approval process
  • Access prerequisites — the training courses and agreements that must be completed before data access can be granted
  • FAQs — frequently asked questions about the application process, eligibility, and data governance
Skylark is at skylark.ucl.ac.uk/NSHD

Variable Metadata Pages

Every variable on OWL and Condor has a dedicated metadata page presenting the same information on both platforms — questionnaire provenance, linked longitudinal variables, category memberships, value labels, and frequency distributions. The NSHD Showcase presents the same variable as a grouped field with sweep-by-sweep distributions via Instances.

Typical journey from discovery to data

Most data requests follow the same sequence of steps across the four platforms:

1

Explore on OWL

Search the data dictionary, browse by category, read questionnaires and topic pages. Build a basket of candidate variables and export it as a CSV. Review the NSHD Metadata page for each variable to understand its provenance, coding, and any caveats.

2

Check the Showcase

For shortlisted variables, click through to the NSHD Showcase via the Field ID to review participant counts and sweep-by-sweep distributions. This helps confirm whether a variable has sufficient coverage for your research question.

3

Submit via Condor

Register on Condor if you are a new user. Build or import your basket of variables and submit a formal data access request linked to your project. Keep each basket to a maximum of 500 variables — if you need more, split across multiple baskets for the same project.

4

Complete prerequisites via Skylark

Complete the required access prerequisites — training courses and data governance agreements — and submit the Data Access Request Form on Skylark. The Skylark data sharing process pages explain what is required and in what order.

5

Receive and release data

Once approved, data is accessed through the UCL Data Safe Haven. When your analysis is complete, submit a DSH Output Request via Skylark to release outputs from the secure environment.
