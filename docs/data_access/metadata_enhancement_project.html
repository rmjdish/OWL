Metadata Enhancement Project

How the NSHD data team is systematically improving variable metadata across 35,000+ variables to make discovery easier and more reliable.

The Metadata Enhancement Project is an ongoing programme of work to transform the quality of metadata held across the NSHD data infrastructure. The project covers all 35,000+ variables in the NSHD repository and is due for completion at the end of 2027. Work is progressing questionnaire by questionnaire — you can check the data coverage of what is available on OWL/NSHD Showcase platforms via the Data Coverage page. The improvements directly affect what you see when browsing variables on OWL, on the NSHD Showcase, and in Condor. This page explains what has been changed and why.

Improvements to existing fields

The following improvements are being applied to all variables as they are processed through the project:

Variable labels

Variable labels are being expanded and rewritten to be fully descriptive, replacing the truncated text inherited from legacy SPSS files which historically imposed strict character limits. The aim is to give researchers an accurate description of what was measured. OWL also gives access to the orginal questionnaire if researchers want to read the full question text.

Age at collection

Where possible, the participant's age at collection is appended to each variable label — for example Standing height — at age 43 years. This makes it immediately clear at which point in the life course a variable was collected, without needing to cross-reference the sweep year. For researchers new to the 1946 birth cohort, this significantly reduces ambiguity when selecting variables across multiple time points.

Longitudinal label standardisation

For variables collected at more than one sweep — repeat measures of the same construct over time — the main body of the label is now standardised across all instances, with only the participant age differing between sweeps. This makes it straightforward to identify and compare all time points of a measure, since they share a consistent label root.

Category structure

All variables are being re-categorised into a new hierarchical topic structure. The previous system had 23 flat top-level categories that were not assigned to all variables, leaving many uncategorised. The new structure uses a multi-level hierarchy of domains, categories, and sub-categories — mirroring UK Biobank's categorisation where possible — so variables can be found by topic browsing as well as by keyword search. Variables can belong to multiple categories simultaneously.

Derived status

The derived variable flag is being fully populated across all variables. Previously this field was only set for some variables. On OWL the Derived Status field clearly indicates 0 (directly measured or recorded) or 1 (derived or calculated from other variables), helping researchers understand whether they are working with raw collected data or a constructed measure.

Missing value codes

The database field that identifies which value labels represent missing data codes — for example 77 (No questionnaire), 99 (Unknown), or 9999 (No examination done) — is being fully populated for all variables. This enables OWL and the NSHD Showcase to correctly exclude these codes from distribution plots and summary statistics, so that only substantive responses are shown in the frequency displays.

Value label consistency

Value labels are being standardised for consistency across variables. For example, "No" may have been coded differently across questionnaires and sweeps — appearing variously as no, No, or NO. These inconsistencies are being resolved so that the same response is labelled identically wherever it appears. Missing value labels are also being identified and added where they were not previously recorded.

Longitudinal linking

Variables collected at different sweeps are being linked together where appropriate. On the NSHD Showcase, grouping requires that the question text and response coding are identical across all sweeps being linked — where the coding changed between sweeps, those variables appear on separate Showcase entries. On OWL, the Linked and Longitudinal Variables section is more flexible and can connect any variables for any reason — including measures where the question wording or coding changed, or variables that form part of the same instrument or scale.

New metadata fields created

Several new metadata fields have been created as part of the project that did not previously exist in the NSHD databases. These are visible on OWL variable metadata pages and, where applicable, on the NSHD Showcase:

Units

A dedicated field capturing the unit of measurement for continuous variables — for example cm, kg, mmHg, or seconds — held separately from the label text. This makes it straightforward to identify what scale a continuous variable is measured on without reading the full label. On OWL, Units appears as a distinct field on the variable metadata page.

Sensitive flag

A flag to identify variables that are sensitive but not entirely hidden from public view — for example variables containing ICD diagnosis codes or BNF medication codes. Previously, variables were either fully visible or fully hidden. The sensitive flag creates an intermediate state, notifying researchers that a variable carries additional sensitivity considerations before they include it in a data request.

Reason Sensitive / Reason Public

Text fields recording, respectively, why a variable has been flagged as sensitive and why a variable is made publicly visible in OWL. These fields provide transparency about the governance decisions behind access controls, so researchers understand the basis on which access is granted or restricted.

Notes

A free-text notes field for variable-specific contextual information that does not fit neatly into other structured fields. Notes may contain measurement conditions — for example whether a height measurement was taken with or without shoes — known caveats about data quality, recoding details, or any other information that helps researchers interpret the variable correctly. Notes are specific to each variable and appear on the OWL variable metadata page; they are not available on the NSHD Showcase.

Distribution plots and statistics

New frequency distribution visualisations have been created for all variables processed through the project. Continuous variables receive a histogram and a table of summary statistics — minimum, deciles 1 through 9, maximum, mean, standard deviation, and variance. Categorical variables receive a bar chart and a response count table. These appear on the OWL variable metadata page and on the NSHD Showcase, with disclosure controls applied: response categories with fewer than 10 observations are suppressed in the display, and continuous distributions are trimmed to the 5th–95th percentile range to reduce the influence of extreme outliers.

Showcase-specific additions

Two further metadata fields have been created specifically for the NSHD Showcase's technical requirements. These fields are used internally by the Showcase to control how variables are displayed and processed, and are visible in the Showcase's field summary panel:

Coded_as

Derived algorithmically from the variable's value labels and data structure, this field classifies each variable as categorical (single response), categorical (multiple responses), or continuous. The classification determines how the Showcase renders the variable's distribution — bar chart for categorical, histogram for continuous — and which summary statistics are calculated. This field is the definitive data type statement for Showcase display purposes, equivalent to the Value Type field shown in the Showcase field summary panel.

Code_type

Records the technical data type of the variable at a database level, supporting the Showcase's internal processing logic. This is a lower-level technical attribute that underpins the Coded_as classification and the Showcase's data handling routines.

Project progress

The Metadata Enhancement Project covers all 35,000+ variables in the NSHD repository and is being worked through questionnaire by questionnaire. Once a questionnaire's variables have been processed, reviewed, and validated, they are deposited to the NSHD Showcase where they become available with the enhanced metadata, new distribution plots, and updated category structure.

The Essential Information page on the NSHD Showcase maintains a live list of which questionnaires have been completed and deposited, and which are currently in progress or in the pipeline. This is the best place to check whether variables from a particular sweep or instrument have been updated.

The project is due for completion at the end of 2026, at which point all variables in the NSHD repository will have been processed, enhanced, and made available on the Showcase with the full set of new metadata fields and distribution visualisations.

Check the live progress list on the NSHD Showcase Essential Information page.
