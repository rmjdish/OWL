OWL, the NSHD Showcase and Condor

OWL, the NSHD Showcase, and Condor each approach NSHD variables from a different angle. OWL and the Showcase both cover around 29,000 variables that have been cleaned and enhanced as part of the Metadata Enhancement Project — they are complementary sources designed to be used together, linked via the Field ID. Condor holds the full 35,000+ variable set and is where baskets are saved and shared ahead of a formal data request, which is submitted via a form on Skylark. Neither OWL nor the Showcase require registration.

How OWL and the Showcase work together

OWL and the NSHD Showcase cover the same pool of around 29,000 cleaned variables but present different information about each one. They are designed to be used in tandem — the Field ID is the link between them, appearing in OWL's Search Data Dictionary and Browse by Category results tables and on each variable metadata page. Clicking the Field ID opens the corresponding Showcase entry directly.

The NSHD Showcase is built on the same platform as the UK Biobank Data Showcase. Researchers familiar with the UK Biobank will find the structure and navigation immediately recognisable, making the Showcase a particularly efficient starting point for those already experienced with UK Biobank variable discovery.

Use OWL when you need

  • The original questionnaire wording and response options for a variable
  • The form, question number, and year of collection
  • All categories a variable belongs to — a variable can appear in multiple
  • Flexible longitudinal linking — variables connected regardless of coding changes, with the strict same-Field-ID subset flagged separately as Truly Longitudinal
  • Notes, caveats, or recoding details specific to the variable
  • Whether a variable is derived, sensitive, or has a later version
  • To download a basket for uploading to Condor

Use the Showcase when you need

  • Total participant and item counts across all sweeps for a field
  • Sweep-by-sweep distribution charts and statistics on one page (Instances)
  • Strict like-for-like comparison — identical question text and coding only
  • The full hierarchical category path showing where a variable sits
  • Technical attributes — Value Type, Sexed, Strata, Array
  • The NSHD variable name for a specific sweep of a multi-instance field
  • A familiar starting point for UK Biobank researchers — the Showcase uses the same platform, so search, filter, and distribution views work in the same way
OWL and the Showcase take different approaches to longitudinal grouping. The Showcase only groups variables where question text and coding are identical across sweeps. OWL's Linked & Longitudinal tab splits results into Truly Longitudinal (the same strict same-Field-ID grouping as the Showcase) and Linked variables, which connects variables for any reason, including where coding or wording changed between sweeps. See the Variable Metadata guide for a full comparison.

How OWL and Condor work together

OWL and Condor cover different scopes and serve different purposes in the variable selection process. OWL is the richer discovery environment — it has questionnaires, topic documentation, and metadata that Condor does not. Condor holds the full variable set and is where baskets are finalised and saved ahead of a formal application.

OWL basket

Best for discovery and exploration. Use OWL to identify and refine your variable list using questionnaires, topic pages, and metadata — resources not available in Condor. Download your basket as a pre-filled Excel data dictionary to use as a reference list or to upload directly into Condor.

  • ~29,000 cleaned and enhanced variables
  • No registration required
  • Download a pre-filled Excel data dictionary for reference or Condor upload
  • Cannot be used directly for a data request

Condor basket

Where baskets are finalised, saved, and shared. Upload your OWL basket or build directly from the full 35,000+ variable set. Save and share your basket with colleagues before linking it to a formal data application via Skylark.

  • Full 35,000+ variable set including uncleaned variables
  • Registration required
  • Upload OWL basket and modify within Condor
  • Save and share baskets with colleagues
  • Data request submitted via form on Skylark — not from Condor
The formal data request is submitted via Skylark, not from within Condor. Once your Condor basket is finalised, complete the Data Access Request Form on Skylark to make your application. Keep each basket to a maximum of 500 variables per submission.

Recommended workflow across all three platforms

The three platforms work best in sequence — use OWL and the Showcase together for discovery, Condor to finalise and save your basket, and Skylark to submit the formal application.

1

Discover and contextualise on OWL — no registration needed

Search the data dictionary, browse by category, explore Popular Variables, and read questionnaire and topic pages. Review variable metadata pages for provenance, coding, derived status, and any caveats. Add variables to your basket as you go and download it as a pre-filled Excel data dictionary when ready.

2

Cross-check on the NSHD Showcase — no registration needed

For shortlisted variables, click the Field ID to open the Showcase entry. Check participant counts at each sweep, compare distributions across time points using Instances, and confirm technical attributes before finalising your list. If you have used the UK Biobank Data Showcase, the layout and navigation will already be familiar.

3

Upload to Condor, finalise and save — registration required

Register on Condor and import your OWL basket export. Make any final adjustments — adding variables from the full 35,000+ set, removing variables, or splitting into multiple baskets if the total exceeds 500 per submission. Save your basket and share it with colleagues if needed.

4

Submit your application via Skylark

Once your Condor basket is finalised, complete the Data Access Request Form on Skylark to submit your formal application. Complete any outstanding access prerequisites — training courses and data governance agreements — before submitting.

OWL and the Showcase currently cover around 29,000 variables — those cleaned as part of the Metadata Enhancement Project. Variables not yet available on OWL or the Showcase can be found and added directly within Condor. Check the NSHD Showcase Essential Information page for the current list of processed questionnaires.
