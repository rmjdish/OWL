Create Documentation Online

Build your topsheet and documentation directly in the browser — add sections, subheadings, lists, tables, and images through the form below, and see exactly how it will look as you go. When you're happy with it, download it as a real Word document to send to us.

Prefer to work in Word instead?

This browser remembers your work automatically as you go (see Save & download below) — but nothing is ever uploaded to a server while you work, everything stays in your own browser. You're also completely free to download the Word document at any point and keep editing it directly in Word instead, the same as any other documentation you'd write from scratch. Use this page for as much or as little of the process as is useful to you.

Save & download

This browser also remembers your work automatically as you go — so navigating away or accidentally closing the tab won't lose everything, as long as you come back in the same browser. It's not a substitute for Save progress below: the auto-saved copy only exists in this one browser, can't be moved to another computer, and is cleared once you download the finished Word document.

Three different things, worth keeping straight:

  • Save progress is for continuing later, in this tool. It downloads a small JSON file — not a Word document — that only this page can read back in; it's not meant to be opened or edited by hand.
  • Download as Word document is the real, final output — open and edit it in Word exactly as you would any other documentation.
  • Once you've downloaded the Word document, that's a one-way trip: it can't be brought back into this online tool — there's no way to upload a Word document here. If you want to pause and resume here, use Save progress instead; if you'd rather finish by hand in Word, download the Word document — just know you're then finishing in Word, not switching back. Either way, once you're done, you can run the finished document through Page Proof to check it over before sending it in.
