Overview

Blood pressure

Blood pressure at 53 years was measured twice, while the survey member was seated and after 5 minutes of rest, using the validated Omron HEM-705 (Omron Corp., ) automated digital oscillometric sphygmomanometer. At age 36 and 43 years blood pressure was measured twice using a Hawksley random zero sphygmomanometer.

Missing for all reasons are coded to 9999 for all variables All are in mmHg (SBP=systolic blood pressure and DBP=diastolic blood pressure)

For 1982 and 1989 Uses raw measure minus random zero Use formulae to adjust for arm circumference: SBP+(32-(1.05(RUAC/10))), DBP+(22-(0.72(RUAC/10)))

1982 First measures: SBPFF DBPFF Second measures: SBPFXX DBPFXX

Use second measure if available – otherwise use first SBP82 DBP82

1989 MW cleaned these variables for a subset who also had a bp measured in 1982. RH followed same procedure to add those not seen in 1982. First measures: SBPF89F DBPF89F Second measures: SBP289F DBP289F

Use second measure – if invalid then use first in a few case. SBP89RH DBP89RH

Also created Use SBP89RH/DBP89RH measure if available – otherwise use first (SBPF89F/DBPF89F) SBP89 DBP89

1999 First measure: SBP991 DBP991 Second measure: SBP992 DBP992

Use second measure if available – otherwise use first SBP99 DBP99
