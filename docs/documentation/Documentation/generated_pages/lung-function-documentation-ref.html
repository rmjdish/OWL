Overview

Lung function cleaning procedure for 1989, 1999 and 06-10

1989 Three measures were taken for both FEV and FVC.

1999 Two measures were taken for FEV and FVC and an assessment given by the nurse as to whether the technique was satisfactory or not.

2006-10 Two measures were taken for FEV and FVC and an assessment given by the nurse as to whether the technique was satisfactory or not.

Step 1

The values were converted to litres (Divide values by 100)

Any values less than 0.30 and more than 9.0 were considered outliers and excluded (these values are considered implausible according to medical practice but have been retained in data file to allow for comparative investigation and checks on potential bias).

In 1999 and 2006/10 those who had ‘unsatisfactory’ techniques were also excluded.

Step 2

The maximum valid value recorded from each study member was computed. If there was only 1 valid measure then this was counted as the ‘maximum’ value; if there were two or more valid values then the maximum was the highest of all the valid values for that study member.

Step 3

The maximum value from the 3 measures was generated provided there were at least 2 valid measures available. (i.e. those who only gave one valid measurement were excluded)

Step 4

Using the Quanjer method [1]

If the difference between the maximum two blows is more than 0.30 L the respondent is this is considered to be an outlier and should be removed.

Step 5

Using the ATS method [2]

The ATS has stricter criteria than the Quanjer method. If the difference between the maximum two blows is more than 0.15 L the respondent is this is considered to be an outlier and should be removed.

Optional

Comparing the NSHD distribution to other European cohorts it appears that the NSHD is systematically lower than these cohorts.

Orfei et al [3] have used the following correction when comparing the 1946 cohort to the 1958 cohort: 0.24L is added to FEV1 and 0.34L to FVC.
