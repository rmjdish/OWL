Overview

Cognition – Dyslexia

| Description of variables | In 1957, when cohort members were aged 11 years, 4281 cohort members were administered tests of general cognitive ability, arithmetic, reading and vocabulary. These tests were developed by National Foundation for Educational Research in England and Wales (Pigeon, 1964). Dyslexia status in was based on the results of the general ability and reading ability tests. All tests were administered by teachers in a school setting. | | Categories of variables*: (may be more than one) | Cognitive Function | | Summary of work undertaken | Derivation of a variable measuring dyslexia status at age 11. Calculated using GA11N [Normalised score of 80-item verbal/non-verbal ability test at 11yrs] and R11r [Reading ability at 11 yrs]. | | Date of submitting documentation | April 2014 | | Output variables (please list names of new variables created) | DYSLEX11 |
