Townsend Index

The Townsend index is a measure of material deprivation within a population. The index uses four variables derived from census data: Percentage unemployment (of those aged 16 and over who are economically active) Percentage overcrowded households (of all households) Percentage no car/vans ownership (of all households) Percentage non-home owners (of all households)

townsend

Purpose : Townsend Index** ** Year : 1999

1. Definition The Townsend index is created by summing z-scores of logged unemployment, logged overcrowding, no car, and renters. -9999 No geocoded data

2. Specification

Percentage unemployed (unemp).

Compute unemp=Perc_unempl.

Percentage overcrowded hh (overcrow).

Compute overcrow=overcrowding.

Percentage no car/van ownership.

Compute nocar=nocarinhouse.

Percentage non-home owners (renting).

Compute renting=renttotal/allhouseholds.

Summarize unemp, overcrow nocar renting /cells=min, max, mean, stddev. *.

Using Paul Norman's code.

Recode unemp, overcrow nocar renting (sysmis=0). Compute unemp=ln(unemp+1). Compute overcrow=ln(overcrow+1). Desc vars=unemp, overcrow nocar renting /SAVE. Compute townsend_scot=(zunemp+zovercrow+znocar+zrenting).

Rank vars=townsend_scot /ntiles(5) /ties=mean.
