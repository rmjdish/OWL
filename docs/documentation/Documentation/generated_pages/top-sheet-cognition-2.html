Overview

Cognition (file2) – Cognitive function in childhood, adolescence and early adulthood

| Description of variables | Cognitive function was first tested at age 8 years in a school setting, and again in this setting at ages 11 and 15 years. A test of verbal comprehension given at the latter age was then re-administered at age 26 years (with 10 additional items of increased difficulty to avoid a ceiling effect), as part of the first interview of the survey member as an adult. | | Categories of variables*: (may be more than one) | Cognitive Function | | Summary of work undertaken | Cognitive scores are standardised for whole population available on each test (-mean/sd) and standardised versions of the summary variables COG8, COG11, COG15 are derived [COG8H, COG11H, COG15H]. These three new summary variables are added to the original cognitive score variables in Cognition (file1). COG8, COG11, COG15 are dropped from files since standardised version should always be used. New standardised versions of WV26R and R26R are derived and added to the existing dataset. | | Names of source variables | VOC8, SC8, R8,PI8 R11, VOC11, GA11, A11 R15, GA15, M15 | | Output variables (please list names of new variables created) | SC8R,R8R,PI8R,NV11R,R11R,R15R,WV26R,SC8N,R8N,PI8N, NV11N,R11N,R15N,NV15R,NV15N,VOC8R,VOC8N,V11R, V11N,A11R,A11N,VOC11R,VOC11N,M15R,M15N, V15R,V15N,GA15R,GA15N,R26R,R26N,GA11R, GA11N,COG8H,COG11H,COG15H, WV26H, R26H |
