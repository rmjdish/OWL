Overview

Cognition – 1999 – functional cognitive performance at age 53

| Description of variables | Cognitive function was first tested at age 8 years in a school setting, and again in this setting at ages 11 and 15 years. With the single exception of a test repeated at age 26 years (reading comprehension) cognitive function was not assessed again until age 43 years. At this time there was a shift away from tests of intellectual ability and towards the assessment of functional cognitive performance (memory, processing speed and motor praxis). Some of these tests were repeated at age 53 years (1999), with the addition at this age of 4 tests measuring verbal ability (the NART), verbal fluency, prospective memory and delayed verbal memory. The NART is the National Adult Reading Test and allows a link back to related tests in childhood. | | Categories of variables: (may be more than one) | Cognitive Function | | Output variables (please list names of new variables created) | recd99c,recm99c,recy99c,intd99c,intm99c,inty99c,serb99c, wlcd99,wlt199,wlin199,vsrw99,vscl99,vsms99,vser99,wlt299, wlin299,nart99,wlt399,wlin399,wltx99,wlinx99,wlt499,wlin499, bat99c,sbat99c,q99c,casenum,VSHT99 ANIN, REMEM are not in data set (but are on SWIFT).
