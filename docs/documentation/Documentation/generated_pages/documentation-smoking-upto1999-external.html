Smoking up to 1999

Smoking status, smoking history and number of cigarettes smoked at ages 20, 25, 31, 36, 43 and 53.

Smoking status and smoking history variables provide the same information with individuals categorised as current smokers, ex-smokers and non-smokers. The smoking status variables only use the response of the study member at that particular questionnaire. The smoking history variables account for responses at previous data collections. The cigsta71c to cigsta99c variables are based on cigsta71 to cigsta99 but have been cleaned to remove inconsistent replies across waves. Non-smokers (code 3) have been changed to ex-smokers (code 2) if they had been recorded as a smoker (1) in previous years. The overall Ns recorded in cigsta66-cigsta99 are the same as cigsta66c to cigsta99c but there are fewer non-smokers in this set of variables as a result of the cleaning.
