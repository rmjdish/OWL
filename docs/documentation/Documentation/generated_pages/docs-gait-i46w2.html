Excessive number of NaNs in two variables:

The variables & have a greater number of NaN available. This is due to the delicate analysis whereby there needs to be a clear heelstrike, midfoot and toe-off for both sides for a minimum of 5 steps present, before the values can be derived. In the elderly cohort, this may not always be the case over each walk, hence the number of NaNs in these and associated standard deviation values may be significantly more prevalent.

Note re. difference in analysis from phase 1 (added by Sarah Keuss 26/6/24):

Sarah Keuss noted that there were results for two walks per task in phase 1 but not in phase 2. Heidi Murray-Smith contacted Patrick Esser (who analysed the phase 2 data) and Thanasis Tektonidis (Patrick Esser’s PhD student who worked on the phase 1 data) and the following explanation was given. In phase 1, the data was analysed as two separate walks: walk 1, the 10-metre walk towards the cone; and walk 2, the 10-metre walk back from the cone. In phase 2, a newer version of the analysis was used which has the automaticity to exclude the turn at the cone. As such, there is a combined walk per task which is an average of the walk to the cone and the walk back from the cone.
