Cleaning notes

Front page - intd25x, intm25x Participants that had missing day of interview (intd25x) month of interview (intm25x) were coded as -9 “Unknown”

Q1-Q3 - proxy25x, proxyrel25x, proxyrel25x_txt, proxyreas25x, proxyreas25_2x, proxyreas25x_txt The gating question (prox25x) was cleaned according to how participants answered the follow-up questions. If details were provided on who helped the participant answer the questions (proxyrel25x), the gating question (proxy25x) would be coded as 2 = “Study member with assistance or someone else completing the questions on behalf of the study member”. This was the case with 4 participants. Participants who did not answer the question if they got help with answering the questionnaire, but then gave details of who helped them. The gating question was coded as 1 = ‘Yes’. Those who gave multiple reasons on why they are getting help in answering the questions (proxyreas25x), a second reason variable was created for these (proxyreas25_2x). Further cleaning was done on participants who did not follow the gating when giving reason for why they got help. The remaining missing values were coded as: -8 = Not applicable -9 = Unknown

Q4 – ret25x Those that did not answer the questions were coded as -9 “Unknown” Q5-Q6 – jobvol25x, jobpwrkhr25x, jobvolhr25x The gating question (jobvol25x) was cleaned according to how participants answered the follow-up questions. If details were provided on the number of hours worked for either paid and/or voluntary work (jobpwrkhr25x and jobvolhr25x), the gating question (jobvol25x) would be coded as 1 = “Yes”. Participants who gave either the hours worked for paid or voluntary work but answered the gating question (jobvol25x) as 0 = ‘No’. The gating question was recoded as 2 = ‘Yes’ New code was generated (-6) for those that spend less than one hour per week for either paid or voluntary work. Those participants that put 0 hours for the number of hours worked (jobpwrkhr25x and jobvolhr25x) but did not answer the gating question, were coded as -8 (not applicable) with the gating question (jobvol25x) coded as 0 = “No”. Those that gave the number of hours worked for at least one of paid or voluntary work and gave 0 hours for the other, the 0 was coded as -8 = “Not applicable”. 75 participants put ‘0’ hours for both voluntary and paid work and said No to working. Coding these as -8 ‘Not applicable’.

Q7 – ghi25x Some participants chose multiple responses, only one response is allowed. The main two that were ticked were “Good” and “Fair”. The more positive response was coded, i.e. “Good” All missing values were coded as -9 “Unknown”

Q8 – delir1225x All missing values were coded as -9 “Unknown”

Q25-Q26 provhelp25x provhelpa25x provhelpb25x provhelpc25x provhelpd25x provhelpe25x provhelpf25x provhelpo25x provhelpo25x_txt The gating question (provhelp25x) was cleaned according to how participants answered the follow-up questions. The missing values -8 = ”Not applicable” and -9 = “Unknown” were cleaned using the updated gating variable.

Where participants marked multiple responses, the highest marked option would be used. If participants marked the gating question as 1= ‘Yes’ that they provided help but marked all follow-up options as 1 = ‘No help’, the gating would be coded as 0 = ‘No’, with all follow-up options coded as -8 = ‘Not applicable’. Where the gating question was coded as 0 = ‘No’ and the follow up questions were either coded as unknown or 1 = ‘No help’, these were then recoded to -8 = ‘Not applicable’.
