During the COVID-19 pandemic, participants were offered several assessment options: in-person clinic visit in London, remote assessment via computer, remote assessment via telephone, or a mix. More details about which assessments were completed via computer vs telephone remote assessment are described in Murray et al. 2024. Two participants completed a mixed visit with some assessments completed via a remove computer visit and the remaining assessments and PET/MRI scan completed in-person.

The assessments were divided as follows: Remote assessments via computer Consent AMIPB complex figure Logical memory – immediate and delayed Matrix reasoning Graded naming test FNAME-12 Delirium questions Personal and family history MyCog STAI and PTQ self-complete questionnaires BRAIN tap test Sleep diary and Actiwatch description CDR AD8 In-person clinic visit in London ECHO, cIMT, ECG MMSE Accelerated forgetting AMIPB complex figure and FNAME Circle tracing Task Set-Shifting Blood and urine collection fNIRS Height and weight Blood pressure UPDRS Gait assessment PET/MRI scan
