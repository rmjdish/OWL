Documentation – I46_braintap – Insight phase 2 For Submission to the NSHD Scientific Support Team | Name of person responsible for cleaning/derivation: | Sarah Keuss (with input and advice from Sarah Buchanan) | | Date of submitting documentation | June 2024 | | Categories of variables: (may be more than one) | Physical Capability, Insight 46 Phase 2 | | Summary of work undertaken | Cleaning / Derivation / Both± Description/Rationale: The BRadykinesia-Akinesia INcoordination (BRAIN) test is a validated, online test of motor speed. See (for example): Giovannoni, G., Van Schalkwyk, J., Fritz, V. U., & Lees, A. J. (1999). Bradykinesia akinesia inco-ordination test (BRAIN TEST): an objective computerised assessment of upper limb motor function. Journal of Neurology, Neurosurgery & Psychiatry, 67(5), 624-629. The original description Noyce, A. J., Nagy, A., Acharya, S., Hadavi, S., Bestwick, J. P., Fearnley, J., ... & Giovannoni, G. (2014). Bradykinesia-akinesia incoordination test: validating an online keyboard test of upper limb function. PLoS One, 9(4). A recent, larger validation Using a Lenovo Thinkpad laptop, participants were instructed to tap as fast and accurately as possible, alternating between the ‘s’ and ‘;’ keys for thirty seconds, with each hand separately. Data was analysed and stored on a secure website. Partway through data collection, the original website became defunct (www.braintaptest.com); n=314 participants were assessed using this. A new interface was used for the rest of data collection (https://predictpd.com/en/braintest); n=104 participants were assessed using this. This has been coded using the variable “BT_version_i46p2.” The following statistics were calculated automatically, for each hand separately: Kinesia Score (KS): the number of key taps in 30 seconds Akinesia Time (AT): mean dwell time on each key (milliseconds) Incoordination score (IS): variance of the interval between key taps (milliseconds) Dysmetria Score (DS): ﻿a weighted index of the number of incorrect key taps, scored in a target fashion (1 point for the correct key, 2 points for immediately adjacent keys and 3 for other keys) then divided by the total number of key taps (i.e., if all keys are hit correctly, the score should be 1.0) The development team did not report any significant changes to the way these statistics were calculated between the old and new interfaces. The new interface has a short practice test for each hand (10 seconds) prior to the actual test. It also provides unadjusted and adjusted values (adjusted values exclude ignored responses; responses are ignored if they are pressed too soon/late or are not part of a valid pair). The values in the current dataset are unadjusted to ensure consistency with the old interface. * Due to restrictions related to the coronavirus pandemic, some participants completed a remote assessment by telephone or video. These participants were offered the option of completing the BRAIN test using a personal computer or tablet. This has been coded using the variable “BT_remote_i46p2.” Missing data: n=24 did not complete the test due to technical/website issues or because they were assessed remotely and did not have access to a tablet or computer.
