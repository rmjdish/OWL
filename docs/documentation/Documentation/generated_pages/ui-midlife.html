Women’s incontinence variables from 1994-2000.

stress94---stress00 (Stress incontinence)

This variable is derived from 2 items: Women who replied positively to the question “Do you ever lose any urine when you cough, sneeze, laugh, run or exercise” and those who provided response of “less than once a month” to “daily” to the question “..during the last 12 months how often have you lost any urine when you did not mean to ..’’ were considered as showing symptoms of stress incontinence. If an individual suffers from only 1 of these 2 symptoms they are coded as none. [These variables are derived from URLYXX and URLEXXX corresponding to the appropriate year]

Value labels: | 0 | | No | | 1 | | Yes | | 9 | | Missing | | 99 | | Non-respondent/ Not appropriate (including men) |

urge94 ---urge00 (Urge incontinence)

This variable is derived from 3 items: Women who replied positively both to the question “do you ever have an urgent and strong desire to pass urine which is difficult to control?” and to the followup question “do you ever lose any urine before you reach the toilet?” and those who provided response of “less than once a month” to “daily” to the question “..during the last 12 months how often have you lost any urine when you did not mean to ..’’ were considered as showing symptoms of stress incontinence. [These variables are derived from URUXX, URLBTXX , URLYXX corresponding to the appropriate year]

Value labels: | 0 | | No | | 1 | | Yes | | 9 | | Missing | | 99 | | Non-respondent/ Not appropriate (including men) |

sev94—sev00 (Severe incontinence)

This variable is derived from 2 items: frequency of reported urine lost over the past year and the amount lost. [These variables are derived from URLYXX, URLYAXX, corresponding to the appropriate year]

Value labels description: | 0 | | Not incontinent | | 1 | | Loss of a few drops of urine, and at most once a month (MILD) | | 2 | | Loss of more than a few drops of urine and at most once a month OR loss of a few drop and occurring twice a month or more over the previous year (MODERATE) | | 3 | | Loss of a more than a few drops of urine and occurring twice a month or more over the previous year (SEVERE) | | 9 | | Missing | | 99 | | Non-respondent/ Not appropriate (including men) |
