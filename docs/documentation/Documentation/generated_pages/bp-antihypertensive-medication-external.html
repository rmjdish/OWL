Overview

Anti-Hypertensive medication (nb all tables are unweighted data) For the 1999 data collection, anti-hypertensive medication was defined as people taking drugs for anti-hypertensive purposes rather than drugs that could have the same effect may not be taken specifically for this purpose. For the 2006-10 data collection the variable created is for those taking anti-hypertensive medication in line with the BNF codes used in 1999 and those taking medications which will lower blood pressure even if it was not prescribed for that purpose. The only additional drugs to be included under the second definition are the potassium sparing and loop diuretics.
