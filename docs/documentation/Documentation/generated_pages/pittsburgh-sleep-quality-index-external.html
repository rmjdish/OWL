Pittsburgh Sleep Quality Index (PSQI)†

It is a self-rated questionnaire which assesses sleep quality and disturbances over a 1-month time period consisting of 19 individual items that generate 7 component scores: subjective sleep quality (psqislpqual); sleep latency (psqilaten); sleep duration (psqidurat); sleep efficiency (psqihse); sleep disturbance (psqidistb); use of sleeping medication (psqimeds); daytime dysfunction due to sleepiness (psqidaydys). The sum of the scores of these seven components yields one global score the Pittsburgh Sleep Quality Index (psqi). The range of possible values is minimum score = 0 (better); maximum score=3 (worse).

Note

The questions relating to the PSQI in the NSHD postal questionnaire (PQ) are questions 57 to 62 the equivalent questions from PSQI questionnaire which are referred to in the PSQI scoring sheet are 1 to 9 (see PSQI scoring and PSQI questionnaire documents). As stated above if any of these questions are missing then any scores calculated using missing questions are also missing. Thus it is important to make sure that all questions are answered. Questions 58 to 62 in the NSHD (PQ) were recoded from range 1-4 to 0-3 to be consistent with the PSQI scoring sheet. †Reference:
Buysse DJ, Reynolds CF, Monk TH, Berman SR, Kupfer DJ. The Pittsburgh Sleep Quality Index: A new instrument for psychiatric practice and research. Psychiatry Res 1989;28:193-213.

To score the PSQI:

Derivation of the 7 components of PSQI and the total global PSQI score were scored as in document: **PSQI scoring **

Psqidistb: Sleep disturbance

The scoring document states that the score for q5j set =0 (q 58j in NSHD) if either the comment or the value is missing. If both comment and frequency missing the score was also set to 0. N= 2222 valid values

Psqilaten: Sleep Latency

The sum from the adding together q5a(q58a NSHD) and q2(q57b NSHD) has N<10 value=2.5 (because q5a=1.5 the mean of two answers circled) the value is rounded up prior to final categorisation. N= 2264 valid values

Psqidaydys: Day dysfunction due to sleepiness

The sum from the adding together q8(q61 NSHD) and q9(q62 NSHD) has N<10 value=0.5 (because q9=0.5 the mean of two answers circled) this needs to be rounded up prior to final categorisation. N= 2418 valid values

Psqihse: Sleep efficiency

This is derived by dividing hours of actual sleep per night q4 or (q57d NSHD) by time duration in hours between time went to bed at night and time got up in the morning and then multiplying by 100 ( see scoring document) An interim variable (durthr) was derived to calculate the time duration(hours) between time going to bed at night and time get up in the morning. This was done by deriving interim variables to aid calculation and checking: go-to-bed day (bday) was set = 1 if survey member reported going to bed in the evening and set = 2 if reported going to bed after midnight and get-up day (gday) was set to 2 for all. These 2 variables were then used to generate a date went-to-bed (datebedt) set =11th Jan 2015 if bday=1 or set = 12th Jan 2015 if bday=2 and date got-up (dateup) set=12th Jan 2015. Then a go-to-bed date-time variable (datebedtime) derived by combining datebedt +bedthr14x (time went to bed at night in hrs 24hr format)+ bedtimm14x (minutes went to bed) and similarly for get-up date-time variable dateuptime using dateup + getthr14x+ getupm14x. Finally durthr (hours) which was used in the derivation of sleep efficiency (see point above) was derived from dateuptime – datebedtime. N= 2382 valid values

Psqislpqual: Overall sleep quality

N<10 has value 0.5; N<10 have value 1.5 these are the mean values of 2 choices made by survey member. N= 2431 valid values

Psqimeds: Need meds to sleep

N= 2420 valid values

PSQI global score: Total

Total = psqidurat + psqidistb+ psqilaten+ psqidaydys +psqihse + psqislpqual+ psqimeds The sum of the 7 component scores yields a global PSQI score with minimum value= 0 (better) to maximum value= 21(worse). Interpretation: PSQI score <= 5 associated with good sleep quality and PSQI score > 5 associated with poor sleep quality. N= 2100 valid values

N.B. Psqislpqual and Psqimeds were originally dropped from the final output dataset as they were duplicates of existing variables (SLQUAL14x and SLMEDI14x respectively). However, they have been recoded from 1- 4 to 0 - 3 for correct psqi scaling so have now been left in.
