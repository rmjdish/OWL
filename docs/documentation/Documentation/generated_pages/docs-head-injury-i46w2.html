Head Injury questionnaire (Self-assessed questionnaire)

(Version 08/08/2017)

These questions will ask about whether you have experienced a head injury, which is an injury involving an impact to your head. We have previously asked brief questions about this, but we would now like to know more detail about any head injuries you may have experienced.

Please take the time to read the questions carefully as it is common for people to forget these details. When completing the questionnaire please use a pen to tick the appropriate response(s) to each question.

All information you give us will be treated in the strictest confidence. Thank you very much for your time and co-operation.
