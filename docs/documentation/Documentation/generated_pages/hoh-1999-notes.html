Overview

Head of Household 1999 (age 53)

A problem was identified with the previous version of Head of Household Social Class 1999 (aged 53) – variable **SC53. **

When the variable was originally created sex was not properly taken account of.

It should be: * If SM is male then HOH class = SM class * If SM is female and there is spouse class then HOH class = spouse class. * If SM is female and there is no spouse class then HOH class = class.

What seems to have happened is the variable was created as: * If there is spouse class then HOH class = spouse class * Else HOH class = SM class.

The variable has been recreated and changed in SWIFT
