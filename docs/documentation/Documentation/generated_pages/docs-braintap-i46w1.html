Overview

Documentation – I46_braintap – Insight phase 1

| Summary of work undertaken | Cleaning / Derivation / Both± Description/Rationale: The Bradykinesia-Akinesia INoordination (BRAIN) Test is a validated, online test of motor speed. This was administered to Insight 46 participants during phase 1 (May 2015- Jan 2018). See (for example): Giovannoni, G., Van Schalkwyk, J., Fritz, V. U., & Lees, A. J. (1999). Bradykinesia akinesia inco-ordination test (BRAIN TEST): an objective computerised assessment of upper limb motor function. Journal of Neurology, Neurosurgery & Psychiatry, 67(5), 624-629. The original description Noyce, A. J., Nagy, A., Acharya, S., Hadavi, S., Bestwick, J. P., Fearnley, J., ... & Giovannoni, G. (2014). Bradykinesia-akinesia incoordination test: validating an online keyboard test of upper limb function. PLoS One, 9(4). A recent, larger validation Using a Lenovo Thinkpad laptop, participants were instructed to tap as fast and accurately as possible, alternating between the ‘s’ and ‘;’ keys for thirty seconds, with each hand separately. Data was analysed and stored on the website (www.braintaptest.com, now defunct). The following statistics were calculated automatically, for each hand separately: Kinesia Score (KS): the number of key taps in 30 seconds Akinesia Time (AT): mean dwell time on each key (milliseconds) Incoordination score (IS): variance of the interval between key taps (milliseconds) Dysmetria Score (DS): ﻿a weighted index of the number of incorrect key taps, scored in a target fashion (1 point for the correct key, 2 points for immediately adjacent keys and 3 for other keys) then divided by the total number of key taps (i.e. if all keys are hit correctly, the score should be 1.0) Cleaning: The data from the website were reconciled to those transcribed manually by study staff. Impossible values have been coded as missing data. In several cases, the hand used for each test may have been recorded incorrectly (indicated by a discrepancy between the data recorded by staff and the website). This discrepancy has been coded with the variable “BT_rightleftuncertain_15“,the data is useable for analyses using a the mean of both hands, or “worst hand” analyses, but should be excluded if relationships with dominant or non-dominant hands are investigated. The website has provided some implausible values: Negative AT values: n=4 DS values of zero: n=23 The entire output for that hand has been discounted for these participants as no assurances could be given for the remainder of the statistics. Missing data: n= 16 did not complete the test, all due to equipment/ website malfunction n=1 only had valid data for one hand (so mean values missing) n=27 excluded due to implausible values (website error) All re-coded as missing: 999 Derived statistics: Means for each hand |
