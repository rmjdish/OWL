Overview

We conducted EFA and CFA analysis (see document “file-list.docx” and folder “mplus models”), and achieved a 3 factor structure for the early teacher rating items. The factors are named Self-control (featuring school related behaviour), External (externalising behaviours) and Internal (internalising behaviours). EFA factor scores might be better suited for studying associations with other covariates because the EFA factors are less correlated than CFA based factor scores. “Adolescent mental health and midlife memory 3 Dec 2012.doc” is manuscript contains detailed technical description of data analysis of the teacher rating. See “file-list.doc” for a list of all support documents.
