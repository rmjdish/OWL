Categories of variablesBlood, urine, and other samples
Summary of work undertakenCleaning

- The blood test results were extracted from individual HTML files into an excel spreadsheet.

- Missing values were coded as -99

- Reasons for missing values were entered manually

Derivation

- Age at blood testing was derived in Excel using date of birth and date of study visit

- eGFR was derived using MDRD equation: 175 x (Scr/88.4)-1.154 x (Age)-0.203 x (0.742 if female) where Scr equals serum creatinine in umol/L

Submitted to BMJ Open 29/01/19. Currently awaiting reviewer selection.

Overview

Bloods were analysed within 24 hours of blood testing.
