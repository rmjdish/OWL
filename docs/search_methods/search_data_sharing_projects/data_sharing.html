About data sharing

Researchers can apply to use NSHD data for their own projects. Each application is for a specific project and a specific set of variables, and every approved project is recorded so that how the data is used can be seen and reported.

In this section you can:

  • Find out how to apply, and what you will need to prepare.
  • Discover projects that have already been approved, and the variables each one asked for.
  • See the numbers behind data sharing: how many applications are made, who makes them, and what they ask for.

How to apply

Applying takes five steps:

  1. Decide which variables you need. Search or browse the variables on OWL and add the ones you want to your basket.
  2. Complete the data dictionary. Download your basket as a pre-marked copy of the data dictionary, or fill it in by hand. This is the file NSHD uses to process your request. How the data dictionary works
  3. Submit your application. Send your application together with your completed data dictionary.
  4. NSHD reviews your application. Your project is checked before it is approved.
  5. Receive your data. Once your project is approved, the variables you asked for are prepared and made available to you through Condor.
You can complete the data dictionary on OWL, by hand, or a mixture of both. Whichever you choose, only the variables marked in the "Request variable" column are included in your application.

See what others have done

Every approved project is listed on Discover Projects, with its title, summary and the variables it asked for. It is a quick way to see how other researchers have used the data, and you can add variables from any project straight to your own basket.
