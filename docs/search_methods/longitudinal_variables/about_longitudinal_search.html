About Longitudinal Search

Go to Longitudinal Search

Longitudinal Search is a dedicated tool for finding NSHD variables that were collected with identical question text and coding across two or more sweeps. Rather than searching the full data dictionary and manually checking whether a measure was repeated, this page surfaces only the subset of Field IDs that genuinely qualify — and for each one, shows exactly how the measure changed across the lifespan, visually and numerically.

What Longitudinal Search is

Longitudinal Search groups every NSHD variable by its Showcase Field ID — the same identifier used by the NSHD Showcase to link variables sharing identical question text and response coding across sweeps. Only Field IDs that appear in two or more sweeps are included; single-sweep variables don't appear here at all, since there is nothing to trace longitudinally.

For each qualifying Field ID, the page shows:

  • The shared variable label, with sweep-specific suffixes like "at age 36 years" removed so it reads as a general measure
  • How many sweeps it was collected at, and the first and last collection years
  • The full list of individual NSHD variable names that make up that Field ID, each linked to its own metadata page
  • A trajectory chart and detail table, revealed by clicking View on any row
As of the most recent data dictionary update, there are over 2,300 longitudinal Field IDs available, with some measures spanning as many as 28 sweeps from 1946 to 2025.

Strict linking explained

The grouping logic behind Longitudinal Search is deliberately strict. Two variables are only grouped together if they share the same Showcase Field ID — which in turn requires that the underlying question text and response coding are identical across the sweeps in question. If a question was reworded, if response categories changed, or if the unit of measurement shifted between sweeps, the NSHD Showcase treats those as separate fields, and so does Longitudinal Search.

This matters because it guarantees that everything shown in a trajectory chart or detail table on this page is a genuine like-for-like comparison. A mean of 168cm in 1982 and a mean of 167cm in 2015 for the same Field ID can be compared directly, because the question that produced each value was asked in exactly the same way.

What this excludes: Variables that measure broadly the same construct but with different wording or coding across sweeps will not appear linked here, even if they would reasonably be considered "the same measure" by a researcher. For that more flexible kind of linkage, see Linked & Longitudinal below.

Searching and filtering

The search box matches against the variable label, the Field ID number, and any individual NSHD variable name within a group — so you can search by a familiar variable name (e.g. ht82) and still find the full longitudinal group it belongs to.

Three filters narrow the result list further:

  • Minimum sweep count — show only Field IDs collected at 2+, 3+, 5+, 7+, or 10+ sweeps, useful when you need a measure with substantial longitudinal depth
  • Topic — restrict results to a single top-level topic area from the data dictionary
  • Column sorting — click any column header (Field ID, Label, Topic, or Sweeps) to sort the result table

A Reset filters button clears the search box, filters, and sort order back to their defaults in one click. Results can be exported as a CSV listing every Field ID, its label, topic, sweep count, year range, and the full list of variable names it contains.

Continuous variable charts

For continuous measures — height, weight, blood pressure, and similar — clicking View renders a line chart showing the mean at each sweep, with a shaded band above and below the line representing the minimum and maximum values observed (after the standard 5th–95th percentile trimming applied throughout OWL). This lets you read both the central trend and how the spread of values changed across sweeps in a single chart.

Hovering over any point on the line shows the exact mean for that sweep. The x-axis is labelled by collection year, and the detail table beneath the chart provides the same information in numeric form — variable name, year, age, mean, standard deviation, minimum, maximum, and series size — for every sweep, to two decimal places.

Categorical variable charts

For categorical measures — self-rated health, yes/no questions, multiple-choice items — a mean has no meaning, so the chart instead shows a stacked bar for each sweep. Each bar is divided into coloured segments, one per response category, sized according to that category's share of respondents at that sweep. A colour-coded legend above the chart identifies each category, and the same colours are reused consistently in the detail table below.

This format makes it straightforward to see how a response distribution shifts with age — for example, watching the proportion reporting "Excellent" health shrink while "Fair" or "Poor" grow across later sweeps. Hovering over any segment shows the exact percentage for that category and sweep.

The detail table for categorical variables replaces the mean/SD/min/max columns with a single Distribution column, showing a compact horizontal version of the same stacked bar plus the percentage breakdown in text, alongside the series size for that sweep.

The detail table

Below every chart, the detail table lists one row per sweep, always including the individual NSHD variable name (linked to its own metadata page), the collection year, and the study member's age at that sweep. Fields shared identically across all sweeps in the group — units, derived status, and variable type — are summarised once above the table rather than repeated on every row, since by definition of the strict linkage they don't vary between sweeps.

Where a sidecar metadata file is unavailable for a particular variable, the corresponding row shows a clear "no data available" state rather than blank or broken cells.

Adding to your basket

Variables can be added to the basket in three ways from this page:

  • Per sweep — tick the checkbox in the Add column of any row inside the expanded detail table to add just that one sweep's variable
  • Whole group at once — tick the checkbox on the main row (before expanding) to add every sweep for that Field ID in one action; or use the "Add all sweeps to basket" button inside the expanded panel
  • Remove in bulk — once every sweep for a group is in the basket, the same button turns into "Remove all sweeps from basket"

The checkbox on each main row also acts as a status indicator even before you interact with it: a filled checkbox means every sweep is already in your basket, a half-filled checkbox means some sweeps are in the basket (perhaps added earlier via Search Data Dictionary or Browse by Category) and some are not, and an empty checkbox means none are yet added.

When to use this vs Linked & Longitudinal

OWL has two different ways to find variables tracked across sweeps, and they answer different questions:

Use Longitudinal Search when

You need a strict, like-for-like comparison across sweeps — identical question and coding guaranteed. Best for building trajectory charts, computing change over time, or confirming a measure is genuinely directly comparable before using it in a longitudinal analysis.

Use Linked & Longitudinal when

You want to trace a broader construct across sweeps even where wording or coding changed — for example connecting different versions of a cognition test, or a scale that was revised partway through the study. Found in the Linked & Longitudinal tab on each variable's own metadata page.

If a variable doesn't appear in Longitudinal Search but you believe it should be comparable across sweeps, check its individual metadata page — it may be connected to related variables via the more flexible Linked & Longitudinal section instead.
