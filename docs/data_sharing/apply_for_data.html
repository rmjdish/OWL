About data sharing

Researchers can apply to use NSHD data for their own projects. Each application is for a specific project and a specific set of variables, and every approved project is recorded so that how the data is used can be seen and reported.

In this section you can:

  • Find out how to apply, and what you will need to prepare.
  • Discover projects that have already been approved, and the variables each one asked for.
  • See the metrics and trends behind data sharing: how many applications are made, who makes them, and what they ask for.

How to apply

Applying takes six steps:

  1. Decide which variables you need. Search and browse OWL, Condor or the data dictionary to select the variables you are interested in.
  2. Complete the data dictionary. Download your basket as a pre-marked copy of the data dictionary, or fill it in by hand. This is the file NSHD uses to process your request. How the data dictionary works
  3. Finalise your basket. Upload your selection to Condor and save it. Condor generates a basket ID, which is what you add to your request.
  4. Submit your application. Complete the data request form on Skylark and attach your completed data dictionary. Add your Condor basket ID to the form, or send it later using the additional users / data request form. What happens next
  5. NSHD reviews your application. Your project is checked before it is approved.
  6. Receive your data. Once your project is approved, the variables you asked for are prepared and made available to you through the UCL Data Safe Haven.

What happens after you apply

Your application and any basket requests are made through online forms on Skylark. Each form you complete starts an automated process, so you and the data sharing team are kept up to date at every stage without anyone having to chase. A data request has to be completed and approved before any data can be released.

  1. Submit the data request formComplete the data request form on Skylark. You can attach your Condor basket ID to it. You
  2. Your request is loggedThe data sharing team is told straight away, a task is created for them, and your request is recorded. Automatic
  3. The committee reviews itThe data sharing committee considers your application and approves it, or comes back to you with questions. Data sharing committee
  4. Complete the confidentiality formsAs each step is finished, you are emailed the next form you need. Submitting each form moves your request on to the next stage. You, prompted automatically
  5. Your data is prepared and sentOnce everything is approved, your basket is built and the data is made available to you through the UCL Data Safe Haven. Data sharing team

Adding a basket

You can attach your Condor basket ID to the data request form, or send it later using the additional users / data request form on Skylark. Either way, quote the application form ID you were given when you applied. It is how your basket is matched to the right project, so the right data is prepared for the right application.

Behind the scenes

Automated requests

Since 2022, requests have been handled by an automated workflow. When a form is submitted it sends emails, creates a task for the team and records the request, and when a task is completed it starts the next step. This is what makes handling requests quicker and keeps the record consistent.

The timings on Metrics and Trends page come from these records.

Jay, our project records system

Jay is an internal web application, used only by NSHD data managers and held on secure servers. It keeps a record of every approved project and links each basket to its project, using a pseudonymised project code.

Baskets are built inside Jay under the project's ID, so it is the record of what each project has been sent, and when.

You never need to use Jay or the workflow yourself. You complete the forms, and the team takes care of the rest.
