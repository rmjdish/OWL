Category Memberships

Category Description
Reaction time [1019] This is a standard manual reaction time (RT) task with visual signal, involving two conditions: 1. Simple, requiring survey members to press one button as quickly as possible following a signal. Eight practice trials were given, followed by 20 real trials. To avoid anticipation there was a variable delay (1-3 sec) between each response and the next signal. 2. Choice, requiring survey members to press one of four buttons as quickly as possible corresponding to which of the numbers 1 to 4 appeared in the signal screen. Eight practice trials were given, followed by 40 real trials. Note that this condition requires both hands to be functioning.
