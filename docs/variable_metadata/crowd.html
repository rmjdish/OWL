Notes CLOSER work package 9: Harmonised childhood environment and adult wellbeing measures. The measure is a median score of overcrowding collected at birth, age 2, 4, 6, 8 & 11. For any cases where data was missing for one or more sweep, the measure was derived using the sweeps where data was available.
