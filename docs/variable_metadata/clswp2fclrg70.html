Notes CLOSER work package 2: Harmonised socio-economic measures. Values are based on variables FOCC57 and FSTAT57 from the 1957 data collection. These were coded to the 1970 version of the OPCS occupational coding scheme. The standard OPCS syntax was used for the derivation of 1970 RG Social class, as no look-up table was available to harmonise 1970 occupation coding's to the 1990-version RG codes
