Category Memberships

Category Description
General health [6022] This category contains data about the general and physical health which also includes experiences of covid symptoms, testing for Coronavirus and suffering from common health illnesses asked in the 2020-2021 covid questionnaires where the participant was 74 years. Healthcare questions were also included in this category.
