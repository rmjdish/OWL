Where should I start?

What you need depends on what you already know.

If you have a specific variable name or keyword in mind, the Data Dictionary Search is fastest — it searches variable names, labels, and descriptions directly and updates as you type.

If you're approaching the data conceptually — say, you know you're interested in respiratory health or childhood cognition but don't know the variable names — start with Topics instead, which groups variables thematically and explains what was measured and when.

If you want to see the original survey instrument a question came from, or you're trying to understand how a variable was actually worded when asked, the Questionnaires archive lets you browse by sweep and respondent type, with variable names annotated directly on the PDFs.

And if you just want to see what other researchers commonly use, Popular Variables shows which measures are most frequently added to project baskets. All of these are reachable from the homepage, or via the search bar at the top of every page.
