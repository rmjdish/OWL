Basket Management

How to add, remove, and export variables using the basket across the OWL.

On this page

  • Adding a single variable
  • Add All to Basket button
  • Pagination for bulk adding
  • Reviewing & exporting
Back to getting started

Every results table across the OWL — Search Data Dictionary, Browse by Category, and Popular Variables — uses the same basket controls, so once you've learned them on one page, they work identically everywhere else. This page walks through each control in detail: adding variables one at a time, the Add All button and its different states, using pagination to add larger numbers of variables in fewer clicks, and reviewing or exporting what you've collected.

Adding a single variable

Every row in a results table has a checkbox in the leftmost Add variable column. Ticking it adds that variable to your basket immediately — there's no separate confirmation step or save button to click afterward.

  • Instant feedback — the checkbox stays ticked once a variable is added, so you can see at a glance which rows on the current page are already in your basket.
  • Untick to remove — clicking a ticked checkbox removes that variable from the basket again, the same way it was added.
  • Header counter — the basket icon in the site header updates its running total the moment you tick or untick a row, so you don't need to open the basket page to confirm something was added.

This is the right approach when you're working through a short, specific list of variables you already know you want, rather than adding everything a search or category returns.

The "Add All to Basket" button

Above every results table sits an Add All to Basket button, which adds every variable currently visible on the page in a single click rather than ticking each row individually. The button changes appearance and label depending on the state of the table:

  • Add all visible variables (teal) — the default state. None, or only some, of the variables currently visible are in your basket yet. Clicking it adds all of them.
  • Remove all visible variables (red) — once every variable currently visible has been added, the button switches to red and its label changes. Clicking it again removes all of those variables from the basket, effectively undoing the bulk add in one click.
  • No visible variables to add (black, disabled) — if your search term or filters narrow the table down to zero matching rows, there's nothing to add. The button greys out, switches to black, and becomes unclickable until your search or filters return at least one result again.

This toggle behaviour means the same button always reflects the current state of the table — you never need to check the basket separately to know whether the button will add or remove variables.

Using pagination to add more at once

The Add All button only acts on variables currently visible on the page — it does not add every result across your entire search, only what's shown in the table at that moment. If your search or filters return more rows than fit on one page, you have two options:

  • Increase the page size first — use the page size selector (15, 30, 50, or 100) to show more rows at once, then click Add All to capture all of them in a single click.
  • Repeat page by page — click Add All on the current page, then move to the next page using the pagination controls and click Add All again, repeating until every page has been covered.

For most working lists, increasing the page size to 100 before using Add All is the fastest route to adding a large set of variables in the fewest number of clicks.

Reviewing and exporting your basket

Once you've added variables — individually, in bulk, or a mix of both — the basket page is where you manage the full list. From there you can review every variable you've collected, remove anything you no longer need, double-check labels and sweep coverage at a glance, and export the complete list as a CSV. The exported file is ready to use directly in a project proposal, a data access request, or as a working variable list for analysis.

The basket persists as you move between pages and tools, so a variable added from a category browse will sit alongside one added from a keyword search — there's no need to finish in one tool before switching to another.
