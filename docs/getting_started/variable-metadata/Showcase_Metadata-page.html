NSHD Showcase (Datashare)

What the NSHD Showcase on Datashare shows for each variable, and how it complements the NSHD metadata page.

On this page

  • Field Summary Panel
  • Data Section
  • Instances
  • Notes
Back to Variable Metadata

The NSHD Showcase is the Datashare portal for the NSHD cohort. Each OWL variable links to its Showcase entry via the Field ID on the NSHD metadata page. Where the NSHD metadata page focuses on questionnaire context and longitudinal linkage, the Showcase focuses on data availability, participant counts, instance structure, and distribution charts. The same disclosure controls apply as on the NSHD metadata page — low cell count suppression for categorical variables and percentile trimming for continuous variables — so plots and statistics will match the NSHD metadata page display.

Field Summary Panel

At the top of every Showcase page is a summary panel listing key technical attributes of the field. Each item is explained below:

  • Participants — the number of unique study members who have at least one data point for this field. For multi-instance fields, this is the number of distinct individuals across all time points combined.
  • Item count — the total number of individual data points available across all instances. For multi-instance fields this will exceed the participant count — for example, if 2,400 participants each have data at 4 time points, item count would be approximately 9,600.
  • Value Type — describes how the data is stored: Categorical (single) means one coded response per participant per instance; Categorical (multiple) means more than one response may be selected; Continuous means a numeric measured value.
  • Sexed — whether the data covers both sexes or is specific to one sex, for example female-only measures such as those from the Women's Health questionnaires.
  • Instances — the number of time points at which this field was collected. Defined(1) means data from a single sweep; Defined(10) means data from ten different time points. The number in brackets corresponds to the number of instance breakdowns shown in the Instances section.
  • Item Type — Data means the field contains actual collected measurements; other types may indicate derived or administrative fields.
  • Version — N/A for most NSHD fields, indicating no versioning has been applied.
  • Stability — Complete means no further data collection is expected for this field and the dataset is finalised; Accruing means additional sweeps may be added in future.
  • Strata — Primary means core cohort data collected from the main study sample; Secondary indicates sub-study or derived data.
  • Array — whether the field holds multiple measurements per participant per visit (array data). The majority of NSHD fields show No.
  • Cost Tier — the data access cost category for this field (shown as dX oX sX). This is relevant when completing a formal data access application through Datashare.
  • Debut — the date this field first became available on the Datashare portal.

Data Section

The Data section provides a top-level summary of what is available for the field. It states the total number of items and participants, identifies the data coding scheme used (linked to its own page on Datashare), and for single-instance fields shows a distribution chart directly.

For fields where combining instances across time points would be misleading — for example a self-rated health question asked at five different sweeps — the Data section notes this explicitly and does not show a combined chart. In these cases, individual charts are presented per instance in the Instances section below.

The same filtering rules apply here as on the NSHD metadata page:

  • Categorical variables — bar chart showing valid response categories. Any category with fewer than 10 responses is suppressed and will not appear. Missing codes are excluded.
  • Continuous variables — histogram showing values within the 5th–95th percentile range. Values in the bottom and top 5% are excluded, as are missing value codes. Summary statistics reflect this trimmed range.

Instances

For fields collected at more than one time point, the Instances section breaks the data down sweep by sweep. Each instance is labelled with its time period and a description of when and how the data was collected — for example, Instance 26: 2006–2010 — Survey carried out at age 60 to 64 years.

Each instance entry shows the number of participants and items at that time point, and a distribution chart for that sweep alone. This makes it straightforward to see how the variable's distribution changed over time — for example, how self-rated health or standing height shifted as the cohort aged from their sixties into their eighties.

The same filtering rules apply to instance-level charts as to the overall Data section:

  • Categorical variables — bar chart per instance. Categories with fewer than 10 responses are suppressed in the same way as on the NSHD metadata page. Missing codes are excluded.
  • Continuous variables — histogram per instance showing values within the 5th–95th percentile range, with the bottom and top 5% excluded. Summary statistics reflect this trimmed range, consistent with the NSHD metadata page display.

The instance numbers (26, 27, 32, 34, 35 etc.) correspond to study sweep codes used internally by Datashare. The label alongside each instance number gives the human-readable year range and collection context, making it straightforward to identify which sweep each chart represents without needing to know the coding scheme.

Notes

The Notes section contains free-text information about the field, primarily listing the OWL variable names and labels covered by this Showcase entry. This is particularly useful for multi-instance fields, where a single Showcase field may encompass several distinct OWL variables each collected at a different sweep.

For example, a self-rated health Showcase field collected at five time points might list in its Notes: ghi09 — How is your health in general? — at age 60–64 years, ghi14x — How is your health in general? — at age 68 years, ghi22x — at age 76 years, ghi23x — at age 77 years, ghi25x — at age 79 years. This makes it possible to cross-reference between the Showcase instance numbers and the specific OWL variable names to use when building a basket or requesting data.

Not all Showcase fields have detailed notes — for simpler single-instance fields the notes may just confirm the OWL variable name and label.
