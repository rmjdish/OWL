NSHD Metadata Page

What each section of the NSHD metadata page contains and how to interpret it.

Clicking any variable name in a results table opens its NSHD metadata page. The page is divided into six sections covering provenance, longitudinal linkage, documentation, category placement, value coding, and distribution summaries. Each section is explained in detail below.

Variable Metadata

The core record for a variable, presented as a table of fields. Each field is described below:

  • Variable — the short code name used to identify this variable in the dataset, for example ghi09 or ht89u. This is the name you would use when requesting data or referencing the variable in analysis.
  • Field ID — a numeric identifier linking directly to the variable's entry on the NSHD Showcase. Clicking the Field ID opens the Showcase page for that variable, where variables sharing the same Field ID and identical question text and coding are grouped together by sweep via the Instances section.
  • Label — a plain-language description of what the variable measures, including the age or year it was collected at, for example How is your health in general? — at age 60–64 years.
  • Card Number — an internal reference linking the variable to a specific section or card within the questionnaire library file. Used for cross-referencing against the original instrument.
  • Form — the data collection instrument the variable came from, for example: postal questionnaire, nurse schedule, home visit, CAPI interview, or medical examination. Together with Question and Year, this tells you exactly which instrument the variable was collected from and in what context.
  • Question — the specific question number within that form that generated this variable, for example 96(a). Together with Form and Year, this allows you to locate the exact question in the original questionnaire.
  • Year — the year (or year range) the data was collected, corresponding to a specific study sweep, for example 2006–10.
  • Derived Status — 0 means the variable was directly measured or recorded during data collection; 1 means it was derived or calculated from one or more other variables rather than collected directly.
  • Later Version — if a more recent or corrected version of this variable exists in the dataset, it is listed here. NA means this is the current version and no replacement has been issued. Always check this field before including a variable in a data request — if a later version exists, you should use that instead.
  • Units — the unit of measurement for continuous variables, for example cm, kg, or mmHg. Shows "Not applicable" for categorical variables where responses are coded categories rather than measured quantities.
  • Sensitive — 0 means the variable is publicly visible in the OWL; 1 means it is restricted and may require additional data access permissions to include in a data request.
  • Reason Public — where applicable, the stated reason this variable is publicly available. NA if not specified.
  • Reason Sensitive — where applicable, the reason access to this variable is restricted, for example due to participant confidentiality. NA if the variable is not restricted.
  • Notes — free-text contextual notes about the variable. This may include which questionnaire section it came from, known caveats about the data, recoding details, measurement conditions such as whether a physical measure was taken with or without shoes, or any other information relevant to correct interpretation and use of the variable. Notes are specific to this variable and may contain information not available anywhere on the NSHD Showcase.

Linked & Longitudinal Variables

This section surfaces related variables that have been deliberately linked to the current one. The linkage is intentionally flexible — variables can be connected for any reason, not just because they are strictly identical across sweeps. Common reasons for linking include:

  • The same or very similar question was asked at another sweep, even if the wording, response options, or coding changed slightly between collections.
  • The variables are part of the same instrument, scale, or composite measure — for example, all items from a particular questionnaire module administered at different ages.
  • A variable has a predecessor or successor version that used a different coding scheme, and the link preserves the conceptual connection across the change.

This flexibility distinguishes the Linked and Longitudinal section from the NSHD Showcase, which only groups variables where the question text and coding are exactly identical. Here, the connection reflects a curatorial judgement about conceptual equivalence or relationship, rather than strict coding consistency.

For each linked variable, the table shows the variable name (which links through to its own NSHD metadata page), a description of what was measured, the year of collection, the form it was collected on, the question number, and the library file. A variable measuring standing height, for example, may have linked versions spanning from age 2 in 1948 through to age 77 in 2023, each listed as a separate row. Note that some of those linked variables may have slightly different labels, forms, or question numbers across sweeps where the collection method changed over time.

Associated Documents

Links to supporting documentation attached directly to this variable. The NSHD metadata page allows documents to be associated at the individual variable level, giving quick access to the source material behind a specific measure. There are two types of document that may appear here:

  • Questionnaires — a direct link to the questionnaire in the NSHD Questionnaires archive that contains this variable. The questionnaire will show the exact wording of the question as it was asked, the response options offered, and the respondent type (study member, parent, school doctor, etc.). This is particularly useful when you need to check precisely how a question was phrased, or to verify the original context before using the variable in analysis.
  • Documents — where available, links to additional technical documentation attached to the variable, such as a body size measurement guide, a topic documentation file, or a derivation specification explaining how a derived variable was calculated. Not all variables will have accompanying documents beyond the questionnaire link — the presence of a document here indicates that additional context specific to this variable has been made available.

Category Memberships

The category or categories this variable belongs to within the Browse by Category hierarchy. Each entry shows the category name and its numeric code, along with a short description of what that category contains.

A variable can belong to more than one category — for example, a body size measure may sit under both an Anthropometry legacy category and a current Body size measures subcategory within the Clinical data branch. Legacy categories reflect an older classification system and are retained for reference alongside the current Browse by Category tree structure. If a variable appears in a legacy category only, it may not be directly navigable from the Browse by Category sidebar but can still be found via search.

Value Labels

For categorical variables, this section lists every coded value and its meaning — for example, 1 = Excellent, 2 = Very good, 3 = Good, 4 = Fair, 5 = Poor. Special system codes such as 77 (No questionnaire) or 99 (Unknown) are also listed here. These labels are essential for correctly interpreting the data, since the dataset itself only holds the numeric codes and the labels are needed to understand what each code represents.

For continuous variables, value labels may still appear in this section, but they represent missing data categories rather than substantive response options — for example, 9999 = No examination done, 7777 = No questionnaire, or −9 = Unknown. These special codes are listed for reference and transparency, but are excluded from all plots and summary statistics in the Frequency Distribution section below. When you request the data, these coded missing values will be present in the dataset and should be accounted for in your analysis, typically by recoding them as missing before any statistical procedures.

Frequency Distribution

A visual and tabular summary of how values are distributed across study members for this variable. The format, content, and exclusion rules differ depending on whether the variable is categorical or continuous. For a sweep-by-sweep comparison of the same measure across multiple time points, see the NSHD Showcase page, where each instance is shown together on a single page.

Categorical variables

A bar chart shows the relative frequency of each coded response category, alongside a table listing each value and its count. Missing value codes (e.g. 77, 99) are excluded from both the chart and the count table.

⚠ Low cell count suppression

Any response category with fewer than 10 observations is suppressed and will not appear in the chart or count table. This is a disclosure control measure to protect participant confidentiality. The actual data you receive through a data access application may therefore include valid response categories that are not shown here.

Continuous variables

A histogram shows the distribution of valid values, alongside a table of summary statistics: minimum, deciles 1 through 9, maximum, mean, standard deviation, variance, and series size. Missing value codes are excluded from both the histogram and all statistics.

⚠ Percentile trimming

Values in the bottom 5% and top 5% of the distribution are excluded from the histogram and all summary statistics. This reduces the influence of extreme outliers on the display. The actual data you receive will contain the full range of valid values, including those outside the displayed range.

The distributions shown here are summaries for orientation only. Due to low cell count suppression (categorical) and percentile trimming (continuous), the display may not represent the complete picture. The full dataset available through a data access application will contain all valid observations.
