How the site is organised

Three core mechanisms make up the OWL: search-first tools, browse-first tools, and the variable basket.

The Data Dictionary Search and the global site search bar both work by keyword. The Data Dictionary searches variable-level metadata specifically — names, labels, descriptions, categories — and pairs with a filter panel for precise narrowing. The site search bar, by contrast, indexes whole pages (titles, headings, body text) and is best for finding documentation rather than individual variables.

Topics and Questionnaires both let you explore without already knowing what you're looking for. Topics organises by subject area across the whole study; Questionnaires organises by sweep, preserving the original chronological structure of data collection. Use whichever matches how you're thinking about the problem — by theme, or by point in time.

As you find variables you want, you can add them to your basket from any variable metadata page. The basket icon near the site search bar tracks your running total and lets you preview the last few items added. From the basket page itself you can review, remove, and export your selection as a CSV — useful for compiling a variable list for a project or data request.
