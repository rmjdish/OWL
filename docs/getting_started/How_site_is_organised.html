How the site is organised

Three core mechanisms make up the OWL: search-first tools, browse-first tools, and the variable basket.

On this page

  • Browse-first tools
  • The basket
Back to getting started

The OWL is built around three core mechanisms. Search-first tools work by keyword, for when you already have something to look for. Browse-first tools let you explore by subject or by sweep without a specific target in mind. The basket ties both together, letting you collect variables as you find them, from either approach , into a single exportable list.

Search-first tools

Three tools share a common toolbar and table layout, so once you know one, you know them all:

  • Search Data Dictionary — search across every variable in the dataset by keyword, then narrow further using the filter bar at the top, which lets you drill into specific topics and subtopics without leaving the results view.
  • Browse by Category — open any category or subcategory page (like a specific questionnaire instrument) to see just the variables within it, in a focused table rather than the full dataset.
  • Popular Variables — see which variables have been added to baskets most often by other researchers between January 2021 and December 2025, limited to variables used more than 15 times, as a shortcut to commonly-used measures.

Every results table on these pages comes with the same set of controls:

  • Search box — filters the current table live as you type.
  • Page size — choose how many rows to show at once (15, 30, 50, or 100).
  • Sortable columns — click any column header to sort the table by that field.
  • Add all to basket — adds every variable currently shown in the results to your basket in one click.
  • Download results (CSV) — exports just the rows currently matching your search and filters.
  • Download data dictionary — downloads the full NSHD Data Dictionary as an Excel file, independent of any filtering you've applied.

Because the toolbar is identical across all three tools, a workflow you build in one — filtering, sorting, exporting — carries over directly to the others.

Browse-first tools

Not every research question starts with a keyword. Topics and Questionnaires are built for that — two different ways of moving through the dataset without already knowing the name of what you need. Topics cuts across the whole 80-year study by subject: physical health, cognition, lifestyle, and so on, with each page explaining how a theme was measured over time. Questionnaires instead preserves the study's original timeline, sweep by sweep, so you can see precisely what was asked, of whom, and in what words at a given point in the study's history. Pick Topics when a theme is your anchor; pick Questionnaires when a year, age, or survey wave is. Both tend to function as a map rather than a destination — pointing toward relevant variables, categories, or instruments rather than listing every variable directly on the page itself.

The basket

The basket lets you collect variables as you find them — from search, category browsing, or questionnaire pages — into a single list you can review and export as a CSV.
