Variable Metadata

Two complementary sources of variable information available across the OWL.

On this page

  • NSHD Metadata Page
  • NSHD Showcase
Back to getting started

Every variable in the OWL has detailed metadata available from two complementary sources. The NSHD Metadata page focuses on questionnaire provenance, longitudinal linkage, category placement, and disclosure-controlled distribution summaries. The NSHD Showcase on Datashare presents the same variable from a data portal perspective, with participant counts, instance breakdowns by sweep, and distribution charts. Together they give a complete picture of a variable before including it in a data access request.

NSHD Metadata Page

Accessed by clicking any variable name in a results table across the OWL — Search Data Dictionary, Browse by Category, or Popular Variables. The page covers six areas: the core metadata fields for the variable, its linked longitudinal equivalents across other sweeps, associated documents such as questionnaires, the category tree it belongs to, coded value labels, and a disclosure-controlled frequency distribution.

This is the best starting point for understanding what a variable actually measures, where it came from in the original questionnaire, and how it connects to equivalent measures at other time points in the study.

NSHD Showcase

Accessed via the Field ID link on the NSHD metadata page. The NSHD Showcase is the Datashare portal for the NSHD cohort and presents each variable as a data field with participant counts, item counts, instance structure, and distribution charts. The same disclosure controls apply as on the NSHD metadata page.

This is the best source for understanding how many participants have data for a variable, whether it was collected at one or multiple time points, and what the distribution looks like across the cohort at each sweep.
