Variable Metadata

Two complementary sources of variable information available across the OWL.

On this page

  • NSHD Metadata Page
  • NSHD Showcase
Back to getting started

Every NSHD variable in the OWL has detailed metadata available from two complementary sources. The NSHD Metadata page is flexible — it allows documentation and questionnaire links to be attached directly to a variable, and lets any variables be linked together longitudinally for whatever reason, whether that is the same question asked at a different sweep, or variables that form part of the same scale. The NSHD Showcase takes a different approach, grouping variables that share the same Field ID into a single page broken down by sweep — but only where the question text and coding are identical across those sweeps. Together they give a complete picture of a variable before including it in a data access request.

NSHD Metadata Page

Accessed by clicking any variable name in a results table across the OWL — Search Data Dictionary, Browse by Category, or Popular Variables. The page covers six areas: the core metadata fields for the variable, its linked longitudinal equivalents across other sweeps, associated documents such as questionnaires, the category tree it belongs to, coded value labels, and a disclosure-controlled frequency distribution.

The Linked and Longitudinal Variables section is deliberately flexible — it can connect any variables together regardless of whether their coding matches. This makes it suitable for tracing a construct across sweeps even where the question wording or response scale changed, or for grouping variables that belong to the same instrument or scale. Documentation files and direct links to questionnaires can also be attached at the variable level, making it the best starting point for understanding what a variable actually measures and where it came from.

NSHD Showcase

Accessed via the Field ID link on the NSHD metadata page. The NSHD Showcase is an externally managed portal that groups variables sharing the same Field ID onto a single page, broken down by sweep via the Instances section. This grouping only applies where the question text and response coding are identical across sweeps — so the Showcase gives a clean, directly comparable view of the same measure at multiple time points.

This is the best source for understanding how many participants have data for a variable at each sweep, and for seeing the distribution of responses or measurements at each time point on a single page. The same disclosure controls apply as on the NSHD metadata page.
