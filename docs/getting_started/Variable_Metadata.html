Variable Metadata

Two complementary sources of variable information, each suited to different questions.

On this page

  • NSHD Metadata Page
  • NSHD Showcase
Back to getting started

Every NSHD variable has metadata available from two complementary sources. The NSHD Metadata page focuses on questionnaire provenance, longitudinal linkage, category placement, and disclosure-controlled distribution summaries. The NSHD Showcase groups variables that share the same Field ID and identical question text and coding onto a single page, broken down by sweep via Instances. Together they give a complete picture of a variable before including it in a data access request.

NSHD Metadata Page

Accessed by clicking any variable name in a results table across the OWL — Search Data Dictionary, Browse by Category, Popular Variables, or the Basket page. The Linked and Longitudinal Variables section is deliberately flexible — it can connect any variables together regardless of whether their coding matches, making it suitable for tracing a construct across sweeps even where the question wording or response scale changed, or for grouping variables that belong to the same instrument or scale. Documentation files and direct links to questionnaires can also be attached at the individual variable level.

NSHD Showcase

Accessed via the Field ID link — available in Search Data Dictionary, Browse by Category results tables, and on the NSHD metadata page. The Showcase groups variables that share the same Field ID and have identical question text and response coding onto a single page, with each sweep presented as a separate instance. This means the Showcase gives a clean, directly comparable view of the same measure across time — but only where strict equivalence holds. The same disclosure controls apply as on the NSHD metadata page.

Which should I use?

I want to know which form, question number, and year a variable was collected

→ NSHD Metadata Page — Form, Question, Card Number, and Year fields give full questionnaire provenance

I want to compare distributions across all sweeps on one page

→ NSHD Showcase — Instances shows charts and stats per sweep where coding is identical

I want to know if a variable is derived or has sensitivity restrictions

→ NSHD Metadata Page — Derived Status, Sensitive, Reason Public, and Reason Sensitive fields

I want to know the exact data type of a variable

→ NSHD Showcase — Value Type field explicitly states categorical single, categorical multiple, or continuous

I want to check if a newer or corrected version of a variable exists

→ NSHD Metadata Page — Later Version field tells you if the variable has been superseded and what to use instead

I want to know whether a variable is from the main cohort or a sub-study

→ NSHD Showcase — Strata field: Primary = core cohort data, Secondary = sub-study or derived

I want additional context about how a variable was measured or any known caveats

→ NSHD Metadata Page — Notes may contain measurement conditions, recoding details, or quality caveats not available on the Showcase

I want to see the full category hierarchy for a variable

→ NSHD Showcase — shows the parent and child category structure for the variable's primary category

I want to see all the categories a variable belongs to

→ NSHD Metadata Page — shows all category memberships; a variable can belong to multiple

I want to find the NSHD variable name for a specific sweep of a Showcase field

→ NSHD Showcase — Notes list the sweep-specific NSHD variable names and labels per instance

I want to link variables across sweeps even if the coding or wording changed

→ NSHD Metadata Page — Linked & Longitudinal links any variables for any reason
