When you click on a variable name in any results table across the OWL — Search Data Dictionary, Browse by Category, or Popular Variables — you are taken to its dedicated metadata page. Each page follows the same structure, covering six areas of information about that variable. This page explains what each section contains and how to interpret it.

Variable Metadata

The core record for a variable, presented as a table of fields. Each field is described below:

  • Variable — the short code name used to identify this variable in the dataset, for example ghi09 or ht89u. This is the name you would use when requesting data.
  • Field ID — a numeric identifier linking directly to the variable's entry in the NSHD data portal (Datashare). Clicking the Field ID opens the portal page for that variable.
  • Label — a plain-language description of what the variable measures, including the age or year it was collected at, for example How is your health in general? — at age 60–64 years.
  • Card Number — an internal reference linking the variable to a specific section or card within the questionnaire library. Used for cross-referencing against the original instrument.
  • Form — the data collection instrument the variable came from, for example: postal questionnaire, nurse schedule, home visit, CAPI interview, or medical examination.
  • Question — the specific question number within that form that generated this variable, for example 96(a).
  • Year — the year (or year range) the data was collected, corresponding to a specific study sweep, for example 2006–10.
  • Derived Status — 0 means the variable was directly measured or recorded; 1 means it was derived or calculated from one or more other variables rather than collected directly.
  • Later Version — if a more recent or corrected version of this variable exists in the dataset, it is listed here. NA means this is the current version.
  • Units — the unit of measurement for continuous variables, for example cm, kg, or mmHg. Shows "Not applicable" for categorical variables where responses are coded categories rather than measured quantities.
  • Sensitive — 0 means the variable is publicly visible in the OWL; 1 means it is restricted and may require additional data access permissions to include in a request.
  • Reason Public — where applicable, the stated reason this variable is publicly available. NA if not specified.
  • Reason Sensitive — where applicable, the reason access to this variable is restricted, for example due to participant confidentiality. NA if the variable is not restricted.
  • Notes — free-text contextual notes about the variable — for example, which questionnaire section it came from, known caveats about the data, recoding details, or measurement conditions.

Linked & Longitudinal Variables

One of the NSHD's greatest strengths is the repeated collection of the same or equivalent measures across sweeps, allowing researchers to track how individuals and the cohort change over time. This section presents a table of related variables — the same construct collected at different ages or time points.

For each linked variable, the table shows the variable name (which links through to its own metadata page), a description of what was measured, the year of collection, the form it was collected on, the question number, and the library file. A variable measuring standing height, for example, may have linked versions spanning from age 2 in 1948 through to age 77 in 2023, each listed as a separate row.

This section is particularly useful when building a longitudinal analysis, since it surfaces all available time points for a measure without needing to search for each one individually.

Associated Documents

Links to supporting documentation relevant to the variable. There are two types of document that may appear here:

  • Questionnaires — a link through to the NSHD Questionnaires archive, where you can view or download the original survey instrument containing this variable. The questionnaire will show the exact wording of the question as it was asked, the response options offered, and the respondent type.
  • Documents — where available, links to additional technical documentation for the variable, such as a body size measurement guide, a topic documentation file, or a derivation specification. Not all variables will have accompanying documents beyond the questionnaire link.

Category Memberships

The category or categories this variable belongs to within the Browse by Category hierarchy. Each entry shows the category name and its numeric code, along with a short description of what that category contains.

A variable can belong to more than one category — for example, a body size measure may sit under both an Anthropometry legacy category and a current Body size measures subcategory within the Clinical data branch. Legacy categories reflect an older classification system and are retained for reference; current categories follow the live Browse by Category tree structure navigable from the sidebar.

Value Labels

For categorical variables, this section lists every coded value and its meaning — for example, 1 = Excellent, 2 = Very good, 3 = Good. Special system codes such as 77 (No questionnaire) or 99 (Unknown) are also listed here. These labels are essential for correctly interpreting the data, since the dataset itself only holds the numeric codes.

For continuous variables, value labels may still appear, but they represent missing data categories rather than substantive response options — for example, 9999 = No examination done, 7777 = No questionnaire, or −9 = Unknown. These special codes are listed for reference and transparency, but are excluded from all plots and summary statistics in the Frequency Distribution section below. When you request the data, these coded missing values will be present in the dataset and should be handled accordingly in your analysis.

Frequency Distribution

A visual and tabular summary of how values are distributed across study members. The format, content, and exclusion rules differ depending on whether the variable is categorical or continuous:

Categorical variables

A bar chart shows the relative frequency of each coded response, alongside a table listing each value and its count. Missing value codes (e.g. 77, 99) are excluded from both the chart and the count table.

⚠ Low cell count suppression

Any response category with fewer than 10 observations is suppressed and will not appear in the chart or table. This is a disclosure control measure. The actual data you receive through a data access application may therefore include values that are not shown here.

Continuous variables

A histogram shows the distribution of values, alongside summary statistics: minimum, deciles 1–9, maximum, mean, standard deviation, variance, and series size. Missing value codes are excluded.

⚠ Percentile trimming

Values in the bottom 5% and top 5% of the distribution are excluded from the histogram and all summary statistics. This reduces the influence of extreme outliers on the display. The actual data you receive will contain the full range of valid values.

The distributions shown here are summaries for orientation only. Due to low cell count suppression and percentile trimming, what is displayed may not represent the complete picture. The full dataset available through a data access application will contain all valid observations, including those not visible here.
